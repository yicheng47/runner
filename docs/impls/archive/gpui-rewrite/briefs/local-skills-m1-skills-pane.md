## Addendum 2026-09-09 — codex correction (posted to the mission after the first clean review)

The codex half above is wrong in two places, verified against codex 0.153.4 on this machine and the Codex docs:

1. **Two roots.** Codex reads `~/.agents/skills` (documented user scope; 28 skills here) **and** the legacy `$CODEX_HOME/skills` (`~/.codex/skills`; 11 here). `RuntimeDefinition.skills_dir` becomes `skills_dirs: &'static [&'static str]` (`[".agents/skills", ".codex/skills"]` for codex, `[".claude/skills"]` for claude-code). `SkillCatalog` carries `roots: Vec<PathBuf>`; entries from every root go into one list in case-insensitive name order across roots (Jason superseded the root-grouped order from the coder's PTY, 2026-09-09); a name under both roots is listed twice with distinct paths; `root_exists` = any root exists. `$CODEX_HOME` substitutes only the `.codex` prefix. `~/.codex/skills/.system` stays skipped (dot-dir) — Codex's system skills are its business, like Claude Code's bundled ones.
2. **Codex has a global off switch.** `[[skills.config]]` in `~/.codex/config.toml`, `path = "<…/SKILL.md>"`, `enabled = false`, path-keyed. `global` for a codex entry = the entry whose `path` equals the marker path **as scanned** (root-joined, not canonicalized): `enabled = false` → `Off`, absent or `true` → `On`. `set_global_enabled` gains a codex branch through `toml_edit` (as `ops/mcp.rs:256`): off upserts one entry for the path (replace an existing entry for that path, never duplicate), on removes every entry whose `path` matches; every other table and entry preserved; missing file → created with only the array; unparsable → untouched + error; trae → error. Since a codex name may exist under both roots, the op takes the entry's path (or name + root), not the bare name.
3. **UI.** Codex rows carry the same `Toggle`; the meta line lists every root (`~/.agents/skills · ~/.codex/skills`); the codex caption is the spec's new text; the empty/missing row names every root; the modal's Enabled row appears for codex too as `Enabled in Codex` with a note naming `[[skills.config]]`. Canvas frames `g8KuD3`, `GIyYH`, `skWOh` are updated.
4. **Tests** per plan §M1.4 codex additions: both roots scanned and ordered, duplicate name → two entries, `CODEX_HOME` moves only the legacy root, one root missing → the other still listed, both missing → `root_exists: false`; the codex `set_global_enabled` cases (append, remove, replace-not-duplicate, sibling tables preserved, missing file, unparsable file).
