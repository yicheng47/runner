  The size is the grammars' parse tables either way: C# 5.2 MB, Swift 4.1, C++ 3.4, Kotlin 3.4, SQL 2.4, PHP 2.1 and Ruby 2.1 MB against about 10 MB for the other 18; arborium's SQL grammar alone is 9.5 MB. The build time on each CI job is measured from m5's pull request.
