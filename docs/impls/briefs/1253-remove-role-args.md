The spec is [`docs/features/1253-remove-role-args.md`](../../features/1253-remove-role-args.md); it wins on detail.

## Problem

The role detail page's Command row joins the raw `role.args` onto the command, so a Codex role with Auto permissions shows `codex --ask-for-approval on-request --sandbox workspace-write`, while the edit form's Args field strips those permission flags and reads empty. Runner stores the permission mode as flags in `role.args`; the forms have no Permissions picker. Custom role arguments go away; `role.args` stays as internal storage for the permission flags.

## Read first

- `crates/runner-app/src/surfaces/roles/logic.rs`: `role_visible_args`, `role_edit_args`, `role_edit_is_dirty`, the composing checks.
- `crates/runner-app/src/surfaces/roles/forms.rs` (both Args `TextField`s), `create.rs` (create request), `edit.rs` (update request), `detail.rs` (Command row string, edit rows).
- `crates/runner-app/src/surfaces/roles/tests.rs`: existing args tests, including the "two words" grouping tests.
- `crates/runner-cli/src/command/cli.rs` (`RoleFields.args`, `--arg`) and `crates/runner-cli/src/command/role.rs` (`role_fields`).
- `docs/guide/concepts/roles.md`; the CLI reference generated by `make guide-cli`.

## Deliverables

- The create form has no Args field, and creating a role sends no extra arguments.
- The edit form shows its Args row only when `role_visible_args` is non-empty; saving a role without that row never drops or changes its permission flags; clearing the row and saving removes the extra arguments.
- The detail Command row shows `command` plus `role_visible_args`, never the permission flags.
- `runner role create/update` no longer accept `--arg`; `role_fields` keeps sending `args: []` on create so the daemon contract is unchanged. Regenerate the CLI reference.
- `docs/guide/concepts/roles.md` stops listing arguments as a role setting.
- No schema, protocol or launch change: existing extra arguments keep applying at launch. Leave `--env` alone. Non-goals: agent-level launch options (#1246), any Pencil work.
