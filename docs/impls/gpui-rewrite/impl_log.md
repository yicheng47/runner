## Standing GPUI rules (learned here; every brief cites them)

- Never `cx.new` a stateful child in a render or data-load path; child entities are created once and reused. Entity identity is manual; notify scope is rebuild cost — a child change must not notify the root unless the root's layout depends on it (M4.4).
- Never `Entity::update` the observing entity inside its own `cx.observe` callback — use the callback's `&mut self` (abort on double lease, M4.4). A child must never read the shell on a path the shell can enter synchronously; route assignments funnel through `NativeRoot::set_route`, child→shell hops are `cx.defer`red (M4.6b, "B1").
- A window with no focused handle has an empty dispatch-context stack, so every contextual binding fails there, including negated predicates such as `!ChatSplit`; every route a root can initially render must focus a tracked handle. Bind OS-level fallbacks with no context when they must work independently of surface focus (M4.6e daily drive).
- A no-context key binding receives the deepest dispatch precedence and therefore beats every contextual binding for the same keystroke; compound fallbacks such as ⌘W must route their surface-specific behavior themselves rather than expecting a narrower binding to win (M4.6e daily drive).
- `window.current_view()` is valid only while rendering (prepaint/paint): it unwraps the rendered-entity stack, which is empty during event dispatch, so calling it inside a mouse/hover/key listener panics and — because the listener runs inside an AppKit callback that cannot unwind — aborts the process. Capture the owning `EntityId` at render time (`cx.entity_id()` in the view, or `window.current_view()` in prepaint as the terminal element does) and move it into the closure (nightly `…1306` crash loop, 2026-08-21).
- Never inject `ESC[2J` into a live grid: on the primary screen alacritty implements it as `Grid::clear_viewport`, scrolling the whole viewport into scrollback, so a synthetic clear duplicates history (M6.6). A TUI's own SIGWINCH repaint plus alacritty's reflow is the whole resize story, as in Zed.
- Terminals outlive views: a session's `Term` lives in the `TerminalBridge` registry for the session's lifetime and panes borrow it through leases; never rebuild a grid from a replay buffer, never attach from render (M6.8).
- `svg()` needs its own `.text_color()` — parent text color does not cascade (M4.5). Deferred layers (selects, popovers, tooltips) cannot be created while already drawing a deferred parent — mount modals as the root's final direct overlay (M4.2). Explicit sizes beat flex measurement for rows whose children paint definite heights, and wrapped text inside an `items_center` column needs a definite-width non-flex text block (`w_full`, `min_w_0`, and `whitespace_normal`) or GPUI measures or paints it at intrinsic single-line width (M4.6c/e).
- Dev profile compiles dependencies at opt-level 2 (gpui-ce/taffy at 3) — taffy monomorphizes inside gpui-ce, so an unoptimized dep graph made every frame layout-bound (M4.4).
- Process: check mission state before landing a branch the crew is still reviewing, or tell the crew the tree is being landed (width-chain mission). Two stray single-token corruptions appeared in the tree during M3.7 from outside the crew — watch for recurrence.
