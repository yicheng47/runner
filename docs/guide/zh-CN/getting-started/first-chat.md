# 第一次聊天

开始一次聊天，让一个智能体在自己的终端中工作。你可以直接选择智能体，也可以使用已保存指令和设置的角色。

## 开始并完成一个小任务

1. [安装智能体并登录](install.md)，然后打开 Runner。
2. 按 **⌘N** / **Ctrl+N** 显示启动器页面。侧边栏中会出现虚线的 **新建标签页** 条目；启动前不会保存标签页。
3. 检查文件夹。默认页的文件夹位于 **搜索智能体和角色** 下方：可选择项目或 **无项目**，使用 **更改** 选择其他文件夹。拆分窗格没有文件夹控件：聊天沿用标签页的项目，并在相邻会话的目录中启动。较矮的拆分窗格会显示更少的最近条目，输入名称可找到其他条目。
4. 输入智能体或角色名称，按 **Enter** 或点击条目。搜索为空时，按 **1–4** 启动对应的最近条目。智能体使用自身配置；角色使用已保存的设置。角色自己的目录优先，除非你使用了 **更改**。
5. 聊天会直接启动，无需填写表单。需要时可在窗格菜单中重命名。
6. 在终端中发送一个小提示，例如：“列出此文件夹顶层的文件，并解释各自的用途。不要修改任何文件。”在智能体自己的终端中完成登录或审批提示。Runner 启动 Claude Code、Codex、Copilot 和 Antigravity 时通常会自动接受目录信任；其他智能体可能会要求你信任该文件夹。
7. 等待智能体回复。你可以继续在它的终端中追问。完成后，点击窗格标题栏右侧、⋯ 之前的 **停止对话（Stop chat）** 图标 ，或在该会话获得焦点时按 **⇧⌘X** / **Ctrl+Shift+X** 。

停止的聊天会保留在 Runner 中。居中的 **对话已停止（Chat stopped）** 卡片提供 **恢复（Resume）** 按钮并显示当前快捷键；使用 × 归档。较矮的窗格会先隐藏徽标和说明，确保恢复按钮可用。如果运行时支持，状态旁的 **恢复对话（Resume chat）** 图标 或 **⇧⌘R** / **Ctrl+Shift+R** 会继续已保存的对话。[会话](../concepts/sessions.md)解释了停止、恢复和关闭的区别。

## 添加另一个窗格

按 **⌘D** / **Ctrl+Shift+D** 向右拆分，或按 **⇧⌘D** / **Alt+Shift+D** 向下拆分。在空窗格的启动器中搜索并启动另一个智能体或角色。每个窗格都有独立会话；拆分不会复制第一个智能体的对话，也不会创建任务。

## 打开 Shell

按 **⌘T** / **Ctrl+Shift+T** 打开终端。先拆分聊天窗格，即可在智能体旁放置 Shell。聊天和终端标签页没有终端抽屉；**⌥F12** / **Alt+F12** 仅用于任务工作区。终端没有停止或重启操作：用 Ctrl+C 中断命令，用 × 或 `exit` 关闭窗格。 在聊天标签页中，命令面板的 **新建终端（New terminal）** 会填入可用空窗格，或打开终端标签页；在任务工作区中则添加抽屉 Shell。除非终端中运行的程序报告自身状态，侧栏中终端的状态圆点显示 Shell 的活动：命令运行时显示“工作中”（包括保持打开的程序，如 `vim` 或 `ssh`），回到提示符时显示“空闲”。macOS 和 Linux 上的 zsh 以及 bash 4.4 或更高版本会标记每条命令的开始与结束，圆点随命令即时变化；其他 Shell（包括 macOS 自带的 bash 3.2、fish 以及 Windows 上的所有 Shell）在终端输出内容时显示“工作中”，无输出两秒后显示“空闲”。

## 关闭并稍后返回

Runner 的后台服务负责管理会话。在 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 中，可以选择询问、保持会话运行或停止会话。选择 **保持运行（Keep running）** 后，重新打开 Runner 会连接到仍在运行的终端。同一区域的 **启动时恢复运行中的智能体（Resume running agents on launch）** 控制 Runner 停止原本正在运行的智能体后的恢复行为；它不会自动重启所有手动停止的聊天。

如需让团队共同完成一个任务，请继续阅读[第一个任务](first-mission.md)。
