# Claude Code 账号

打开 **设置 → 智能体 → Claude Code → 账号（Settings → Agents → Claude Code → Accounts）** 管理独立的 Claude Code 登录。原有原生登录显示为 **Personal** 。Runner 保存账号名称、文件夹与选择；Claude Code 在各自配置文件夹和凭据存储中保留登录。

## 添加账号

选择 **添加账户（Add account）** ，输入名称，文件夹保留 Auto，或用 **浏览（Browse）** 选择已有账号文件夹。Auto 按名称推导路径，例如 `~/.claude-work`。默认勾选 **使用 Personal 的设置（Use Personal’s settings）** ；取消勾选可保留独立配置。选择 **添加并登录（Add and log in）** ，完成 Claude Code 浏览器登录。已有登录的文件夹会直接识别，无需再次登录。Runner 为新增的已登录账号完成初始设置，使首次交互聊天跳过 Claude Code 引导。登录过程中， **打开登录页面（Open sign-in page）** 重新打开页面， **取消（Cancel）** 停止尝试。

每个账号显示登录状态、邮箱及可获取的组织或套餐信息。已登录账号也可能不显示套餐标签。

## 切换当前账号

在已登录账号旁选择 **使用（Use）** ，或从用量弹出面板的 Claude Code 下拉框选择账号。下拉框列出已登录账号及其每周用量。 **管理账户…（Manage accounts…）** 打开 Claude Code 设置页。弹出面板、页脚和 **设置 → 用量（Settings → Usage）** 显示当前账号的用量。用量设置可控制侧边栏徽章、检查间隔与 5 小时窗口。接近限额通知仅涵盖当前账号。

所选账号显示 **当前（Active）** ；若同时为 **主账户（main）** ，两个标记会一起出现。

当前账号用于新的直接聊天、角色聊天、小队成员、恢复的聊天与重启后的恢复。运行中的会话保留原账号。配置多个账号时，Claude Code 窗格在标题后显示账号，侧面板显示 **账户（Account）** 和 `config` 文件夹。

角色或启动环境显式设置 `CLAUDE_CONFIG_DIR` 时，仍使用该固定值。显式固定为 `~/.claude` 与原始原生登录不同，后者不设置该变量。

## 恢复与分叉

暂停的聊天会说明原来运行的账号，以及将继续对话的当前账号。 **恢复（Resume）** 继续同一条已保存对话；切换账号不会复制或移动历史。分叉会在当前账号文件夹中创建独立对话。即使忘记了非当前账号，现有聊天仍保留记录的历史位置。

使用 Claude Code 的 `/clear` 开始新对话时，使用的是运行该进程的账号。例如用 Work 恢复 Personal 的对话后，`/clear` 会在 Work 文件夹中创建新对话，之后的恢复也跟随新历史。进程运行时选择另一个当前账号不会改变这个位置。

从未添加其他账号的配置保持原有的原生启动、恢复、分叉和用量行为，不显示账号标签或下拉框。

## 共享主账号配置

在另一个账号行中选择 **使用 Personal 的设置（Use Personal’s settings）** ，然后确认。名称跟随当前主账号。Runner 共享全局记忆、技能、智能体、命令、已启用且已安装的插件，以及用于新会话的设置和用户 MCP 服务器。它在账号自己的 `skills/` 中逐项添加技能链接，保留同名本地技能、同步技能与点开头文件夹。主账号新增技能会在下一次共享启动时可用。每个账号保留自己的插件目录、缓存及已安装/同步状态；共享插件在启动时从主账号安装目录加载。账号行显示共享技能/插件数量及保留的本地状态。现有文件和链接保留；自有设置文件或显式角色设置覆盖仍有效。

在账号 **⋯** 菜单中选择 **停止使用 Personal 的设置（Stop using Personal’s settings）** 即可断开。Runner 只删除自己创建且目标仍匹配记录的链接，包括逐项技能链接。真实技能目录、本地/同步技能与插件状态保留。移除账号使用相同清理方式。文件夹、自有文件、登录和对话历史仍保留在磁盘。Windows 上共享使用目录联接与记忆导入，无需启用符号链接。

**设置 → 智能体 → Claude Code → 技能 / MCP（Settings → Agents → Claude Code → Skills / MCP）** 默认显示主账号；通过下拉框选择其他账号可查看和编辑其独立配置。共享账号会显示共享说明。此选择不改变当前账号，每次进入页面会重置。**设为主账户（Make main）** 将默认配置所有者、模型发现与更新通道查询切换到所选账号。升级为主账号后，其受管理链接会移除，其他关联账号跟随新所有者。其自有文件成为共享配置；Runner 不复制原主账号文件。如果文件夹不可访问而无法完成，仍保留原主账号。恢复访问后，在账号页选择 **重试（Retry）** 。涉及的账号需等待更改完成才能启动；待处理更改在重启后仍保留。

## 重命名、设为主账号、退出登录或移除

账号 **⋯** 菜单提供 **重命名（Rename）** 、 **设为主账户（Make main）** 、 **在访达中显示（Reveal in Finder）** （Windows 为 **Show in Explorer** ）、 **退出登录（Sign out）** 及 **移除（Remove）** 。重命名不改变文件夹。主账号表示共享配置所有者，更改主账号不会改变账号的登录目标。

**退出登录（Sign out）** 仅在账号已登录时显示，并始终先请求确认。Claude Code 移除账号登录凭据；文件夹、设置和对话历史保留，选择 **登录（Log in）** 即可重新登录。退出不会改变主账号、当前账号或共享配置选择。当前账号仍显示 **当前（Active）** ，在重新登录或切换账号之前，新的 Claude Code 聊天会以未登录状态启动。退出原始原生账号也会让终端中的 `claude` 和其他使用 `~/.claude` 的应用退出登录。运行中的聊天和任务会话会保留登录状态，直到 Claude Code 要求重新登录；确认框会显示会话数量。

菜单标签保持单行，过长账号名会缩短显示。主账号、当前账号和原始原生账号不能移除；悬停禁用的移除项可查看原因。移除其他账号会立即让 Runner 忘记它，磁盘上的文件夹、文件和登录保留。如需同时移除登录凭据，请先退出登录。移除当前账号前，请先切换到另一个账号。
