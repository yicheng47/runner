# 聊天、标签页与窗口

将独立会话排列为拆分标签页，在侧边栏组织工作，并使用多个窗口，同时明确当前控制的是哪个终端。

## 认识三个层级

| 层级 | 承载的内容 |
| --- | --- |
| 窗口 | 真实的操作系统窗口 |
| 标签页 | 一组窗格，在项目侧边栏中对应一个条目 |
| 窗格 | 承载单个聊天或 Shell 会话的槽位 |

**⌘N** / **Ctrl+N** 或侧边栏中的 **新建标签页** 在工作区显示启动器页面，并在其项目或最近记录下显示虚线的 **新建标签页** 条目。只有启动聊天、终端或任务后才保存标签页，并替换该条目。条目无处显示时（活动视图中或项目已折叠），改为选中侧边栏中的 **新建标签页**。该页面没有窗格标题栏或拆分菜单；每个步骤上方都保留 Runner 标志和“开始新工作”。页面右上角的 **×**、悬停条目时出现的 **×** 以及 **⌘W** / **Ctrl+Shift+W** 会关闭启动器并返回之前的标签页或页面，在默认页按 Esc 也是如此。没有可返回的标签页或页面时，启动器保持显示且不显示 ×。选择任意侧边栏条目也会离开启动器。**⌘T** / **Ctrl+Shift+T** 在可用空窗格或新标签页中启动 Shell。智能体需要共享消息流时，请使用[任务](../concepts/missions.md)。

每个窗格都是独立卡片：40 px 标题栏、圆角边框，卡片之间以及卡片与展开的侧边栏之间均为 6 px 间距。外侧留白保持 8 px，侧边栏收起时的左侧留白也为 8 px。标题栏包含运行时、名称、可用时的账户、状态、菜单、拆分按钮和 ×。侧面板也是独立卡片；其开关位于窗格区域右上角。只有终端的标签页没有侧面板；在聊天与终端拆分的标签页中，终端获得焦点时侧面板保持打开，并显示最近获得焦点的聊天。

聊天运行时，点击标题栏右侧、菜单之前的 **停止对话（Stop chat）** 图标；停止后，点击 **恢复对话（Resume chat）** 图标。按钮始终可见，位置不随状态变化；状态仅显示当前状态。启动和恢复过程中没有生命周期按钮。窄窗格会依次隐藏详细状态、截短名称、隐藏状态文字；操作按钮始终可见。停止的聊天显示居中的 **对话已停止（Chat stopped）** 卡片，只有 **恢复（Resume）** 按钮和当前快捷键；× 用于归档。较矮的窗格会先隐藏徽标、截短或隐藏说明，只有在恢复按钮仍无法放下时才隐藏标题。**⇧⌘X** / **Ctrl+Shift+X** 与 **⇧⌘R** / **Ctrl+Shift+R** 作用于焦点聊天。菜单提供停止或恢复、派生对话、重命名；× 会归档聊天，仍在运行时先确认。终端菜单只有重命名。用 ×、关闭快捷键或侧边栏操作关闭终端时，即使命令仍在运行，也不会弹出确认；远程窗口同样如此。Shell 以任意退出码结束时都会关闭窗格；正常退出应用或更新后的终端恢复保持原样。

## 拆分与导航

使用 **⌘D** / **Ctrl+D** 向右拆分， **⇧⌘D** / **Ctrl+Shift+D** 向下拆分。在空窗格的启动器中搜索智能体或角色，选择 **终端** 启动 Shell，或从侧边栏选择聊天。在拆分标签页中，拖动窗格运行时图标前的六点拖柄可调整布局；布局选择器提供常用排列。拆分数量受窗口可用空间限制。新窗口会根据打开时已保存的侧边栏宽度和缩放比例设置固定最小尺寸，并为侧边栏的固定控件留出足够高度。之后调整缩放或侧边栏宽度不会更新已打开窗口的最小尺寸。

使用 **⌘[** / **Ctrl+[** 和 **⌘]** / **Ctrl+]** 在窗格间移动焦点。 **⌘1–9** / **Ctrl+1–9** 选择对应的可见侧边栏行：两种视图中的标签页或任务。 **⇧⌘[** / **Ctrl+Shift+[** 和 **⇧⌘]** / **Ctrl+Shift+]** 在最近查看的页面间切换。

从 Finder 或文件资源管理器将文件拖到聊天窗格、任务抽屉终端或任务成员终端，会在提示处插入路径，并像粘贴文件一样加引号。文件悬停时终端高亮，放下后获得焦点；按 Return 前不会执行任何内容。

拆分 Shell 时，Runner 跟随 Shell 报告的工作目录。在 macOS 上会为 zsh 与 bash 安装目录报告。Windows Shell 若没有自己的目录报告提示符，即使执行过 `cd`，拆分仍使用原启动目录。

## 在终端中查找

在聊天窗格、终端、任务成员终端或任务抽屉终端中按 **⌘F** / **Ctrl+Shift+F**，会在终端右上角打开查找栏；终端尺寸保持不变。终端中选中的文本会填入查询内容；查找栏已打开时再次按下快捷键会选中查询内容。每个窗格都有自己的查找栏，关闭前会保留其查询内容。Windows 和 Linux 上， **Ctrl+F** 仍会送入 Shell。

输入时会实时更新匹配项，范围包括输出及其回滚内容，也包括折行到下一行的文本。普通查询不区分大小写；打开 **Aa** 可区分大小写，打开 **.\*** 可使用正则表达式搜索。普通查询也会忽略组合附加符号、emoji 变体选择符和连接符，终端将它们与所修饰的字符存放在一起，因此选中或粘贴的分解形式 é、❤️ 或组合 emoji 都能找到。由 e 加组合重音构成的分解形式也会匹配普通的 e，而预组合的 é 仍只匹配自身；只含这类符号的查询视为空查询。正则表达式无法匹配这些符号本身。计数显示当前匹配项和总数，最多显示 1000+。无匹配时以红色显示 **无结果**，模式无效时显示 **正则表达式无效**，并保留上一次的匹配高亮，直到模式重新有效。所有可见匹配项以琥珀色淡色标出，当前匹配项为实心琥珀色。

匹配项从最新输出开始编号。Enter 或 **⌘G** / **F3** 移到下一个更早的匹配项，⇧Enter 或 **⇧⌘G** / **Shift+F3** 移到上一个更新的匹配项；到达两端时循环。只有匹配项不在屏幕上时终端才会滚动，并将其置于中间。查找栏打开期间，新输出会更新匹配项和计数，当前匹配项保持在原文本上；选中匹配项后，视图保持不动。

查找栏获得焦点时，Esc 关闭查找栏；点击终端使其获得焦点后，Esc 会送给程序。用 Esc 或 **×** 关闭会清除高亮，并将终端滚回打开查找前的位置；切换到其他标签页或任务，或从任务成员切换到其他成员或消息流时，查找也会以同样的方式关闭。切换成员时任务抽屉终端仍然显示，因此它的查找保持打开。使用备用屏幕的程序（例如 `less`、`vim` 或全屏智能体界面）在备用屏幕上没有回滚内容，因此查找只搜索可见屏幕，查找栏会提示这一点。

## 组织侧边栏

使用侧边栏右键菜单重命名和整理标签页、分组到文件夹，以及固定常用工作。[项目](../concepts/projects.md)按目录分组，文件夹则组织侧边栏条目。状态标记显示活动、需要关注和已停止会话。用它找到需要检查的终端，不要将空闲标记视为审查完成。

使用搜索旁的列表筛选按钮，在默认的 **项目（Projects）** 与 **活动（Active）** 之间切换。Runner 会记住选择。活动视图分为 **智能体（Agents）** 和 **终端（Terminals）** 两组，隐藏空分组并显示可见数量。智能体组同时包含聊天和任务，聊天与其关联任务组成与项目视图相同的关联分组；已结束的任务会留在分组中，直到你将其归档。点击智能体或终端标题可折叠或展开；折叠状态会被记住。活动视图包含运行中的聊天、终端和具有活动成员的任务，包括空闲智能体和 Shell。每组内按标签页与任务创建时间从早到晚排列，新工作加入末尾；状态变化、未读输出、重命名和重启不会移动行。第二行显示项目与相对目录，项目外工作则显示工作目录。重命名只改标题，位置仍保留。

活动视图与项目视图一样，每个标签页占一行。包含任意智能体窗格的标签页显示在智能体组；只有终端的标签页显示在终端组。拆分标签页使用拆分图标，名称默认来自第一个聊天或终端窗格，除非手动命名。选择行会打开需要关注的窗格；没有待关注项时打开上次获得焦点的窗格。任务成员汇总成一行。已停止的聊天或未关联任务只有存在未读输出或错误时才保留，已关联任务则留在分组中直到归档；仅被选中不会使行继续显示。已完成的未读回复保留到查看，错误保留到清除。所有运行中的终端均列出，包括空闲 Shell；终端退出后立即关闭。终端活动使用 Runner 现有的基于输出的忙碌估计，不包含抽屉终端。活动视图保留右键菜单；拖动和排序仍在项目视图中进行。

安装并启用 Codex 和 Claude 后，页脚显示实时每周用量。刷新失败或 Runner 重启时，会保留上次获取的用量及其更新时间；重启后，自那次获取以来已重置的限额不再显示。点击可打开用量面板，查看其他受支持提供商。只有其他用量提供商时，会显示 **用量（Usage）** 标签以便打开。独立齿轮打开设置。Runner 有更新时会显示在名称旁。

**⌘K** / **Ctrl+K** 打开命令面板，查找聊天、任务、角色、小队和命令。 **⌘S** / **Ctrl+S** 切换侧边栏。

## 聊天下方的关联任务

智能体从聊天中启动的任务会关联到该聊天。在项目视图中，该聊天的标签页领起一个分组，关联线从聊天连到每个关联任务。每个任务行显示任务状态：需要你处理时显示举手图标，失败时显示警示图标，工作中显示加载图标，稳定下来且有未读输出时显示圆点。没有成员运行后，任务行与其他已停止的任务相同：灰色旗标，仅在有未读输出时显示圆点。每当任务变为需要处理、失败或稳定，聊天会收到一行简短的 `[runner]` 汇报，见[让智能体操作 Runner](drive-runner-from-agents.md#从-runner-聊天启动)。

点击聊天行上的折叠箭头，可把分组折叠为一行，显示其中任务数量及最紧急的状态，顺序为需要处理、失败、工作中、已稳定。Runner 会记住折叠的分组。活动视图中的折叠箭头作用相同，在任一视图中折叠分组，两个视图中都会折叠。在活动视图中，折叠后的行保持原有高度，用这一汇总代替文件夹行，并在末尾显示最紧急状态的图标；展开后文件夹行恢复。折叠分组中的任务没有数字快捷键。拖动或固定作用于整个分组：在关联任务上固定或取消固定，会固定或取消固定该聊天的标签页。归档聊天会解散分组，其任务保留为普通行；归档任务会将其移出分组。

要手动关联任务，把任务行拖到智能体聊天行的中部，该行会显示 **关联到 <聊天>（Link to <chat>）**；行的顶部和底部仍显示常规的排序标记。放在分组的任务之间会把任务关联到该分组的聊天并放在该位置；标签页包含多个智能体聊天时会询问关联哪一个。任务菜单中有 **关联到聊天（Link to chat）**，这是一个带搜索框的子菜单，列出任务所属项目中的智能体聊天；任务已关联时还有 **与 <聊天> 解除关联（Unlink from <chat>）**。在活动视图中通过此菜单关联。只能关联未归档的智能体聊天，且它须与任务属于同一项目，或两者都不属于项目；已关联的任务再次关联时会改为新聊天。聊天会收到一行包含任务当前状态的 `[runner]` 汇报。

把关联任务拖出分组，放到项目的普通行之间即在该处解除关联；放到固定行之间则解除关联并固定。**与 <聊天> 解除关联** 会把任务放在分组正下方；如果分组已固定，则把任务放回其项目且不固定。最后一个任务离开后，分组解散，聊天保持原位。任务标题栏显示 **已关联 <聊天>（linked to <chat>）**，点击可打开该聊天；聊天已归档时显示 **已关联 <聊天>（已归档）**。显示另一台电脑的窗口会显示其分组，但不能关联或解除关联任务。

## 使用另一个窗口

按 **⇧⌘N** / **Ctrl+Shift+N** 打开另一个 Runner 窗口。如果聊天或任务正由其他窗口控制，会显示 **在其他窗口中打开（Open in another window）** 覆盖层。使用交接控制聚焦原窗口或将内容移到这里。一个终端同时只属于一个窗口；覆盖层防止两个窗口发送冲突输入。

按 **⇧⌘W** / **Alt+F4** 关闭窗口。布局会保存，会话可以保持运行。Windows 关闭最后一个窗口时遵循 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 。macOS 上退出应用与关闭窗口是不同操作。

Windows 上，从开始菜单、快捷方式或任务栏再次启动已运行的 Runner，会将现有应用置前，而非启动第二份：主窗口已关闭则重新打开，已最小化则还原。Runner 正在退出时会等待其退出再启动；若 10 秒后仍在运行，则仍会启动另一份。开发版与已安装版是独立应用，可以并行运行。

**⌘W** / **Ctrl+Shift+W** 作用于焦点窗格或聊天标签页（焦点在任务抽屉时隐藏抽屉，或关闭启动器页面），不同于关闭整个窗口。明确要停止智能体时使用 **停止（Stop）** ，要将聊天移出活动列表时使用 **归档（Archive）** 。

后台通知在 **设置 → 通知（Settings → Notifications）** 中配置。聊天事件默认启用，任务事件需主动开启。点击通知会打开对应聊天或任务。当前窗口显示另一台电脑时，本地通知仍可能出现；点击后会让一个窗口返回本机并打开本地条目。

所有默认快捷键与自定义方式见[键盘快捷键](../reference/keyboard-shortcuts.md)。

## 在另一台电脑上工作

登录后，从侧边栏选择电脑；登录方法见[远程访问](remote-access.md)。聊天创建、窗格拆分和调整大小、Shell 窗格、聊天生命周期与侧边栏组织都在主机上使用相同控制。远程任务使用相同消息流、回答卡片、收件人输入框、成员标签页和终端抽屉。启动器的小队步骤列出主机小队；创建或编辑小队需在主机完成。可用操作取决于主机版本。命令面板搜索该电脑的聊天与任务；角色和小队打开主机只读列表，并提供聊天与任务启动操作。创建、编辑、删除角色或小队，以及设置和已归档项目，需要返回本机后操作。

启动器使用主机的智能体和角色，并显示主机当前 Claude 账号。**更改** 打开主机的文件夹浏览器；本地窗口使用操作系统文件夹选择器。启动器为聊天和任务列出主机项目。启动器的最近记录跨项目和窗口共享，本机与每台远程主机分别保存。使用 ↑/↓ 和 Enter 选择搜索结果或固定条目；在默认页按 Esc 返回之前的标签页或页面；拆分窗格中按 Esc 清空搜索。返回本机会还原本机标签页、选择和侧边栏状态。
