# 聊天、标签页与窗口

将独立会话排列为拆分标签页，在侧边栏组织工作，并使用多个窗口，同时明确当前控制的是哪个终端。

## 认识三个层级

| 层级 | 承载的内容 |
| --- | --- |
| 窗口 | 真实的操作系统窗口 |
| 标签页 | 一组窗格，在项目侧边栏中对应一个条目 |
| 窗格 | 承载单个聊天或 Shell 会话的槽位 |

**⌘N** / **Ctrl+N** 以及侧边栏或命令面板中的 **新建标签页** 在工作区显示启动器页面，在可编辑的选择器中预选最近标签页的项目，使用其文件夹，并在最近记录下显示虚线的 **新建标签页** 条目。启动器已显示时，使用打开页面时所在标签页的项目；若该标签页已不存在，则使用最近查看的标签页。最近记录中的标签页或没有标签页时，选择 **无项目**。侧边栏不会选中或展开预选的项目。远程电脑使用各自的标签页和项目。最近记录旁的 **+** 始终以 **无项目** 开始。项目的 **+** 把条目放在该项目下，并将页面的项目选择器锁定到该项目，与拆分窗格相同；见[项目](../concepts/projects.md)。**⇧⌘M** / **Ctrl+Shift+M** 和从小队启动时，选择器保持可编辑并预选当前活动项目，条目位于最近记录下。条目停留在页面打开时的位置，之后无论选择器或 **更改** 如何变化都不移动，启动的内容归入选择器显示的项目。只有启动聊天、终端或任务后才保存标签页，并替换该条目。条目无处显示时（活动视图中或所在分区已折叠），改为选中侧边栏中的 **新建标签页**，不会选中预选项目的条目。选择项目或按 Esc 关闭项目菜单后，焦点返回启动器的搜索框，↑/↓ 可继续在条目间移动。该页面没有窗格标题栏或拆分菜单；每个步骤上方都保留 Runner 标志和“开始新工作”。页面右上角的 **×**、悬停条目时出现的 **×** 以及 **⌘W** / **Ctrl+Shift+W** 会关闭启动器并返回之前的标签页或页面，在默认页按 Esc 也是如此。没有可返回的标签页或页面时，启动器保持显示且不显示 ×。选择任意侧边栏条目也会离开启动器。**⌘T** / **Ctrl+Shift+T** 在可用空窗格或新标签页中启动 Shell。智能体需要共享消息流时，请使用[任务](../concepts/missions.md)。

归档或关闭当前标签页，或归档正在显示的任务后，会显示最近查看的标签页；如果它已在另一个窗口中打开，则跳过它，除非所有标签页都已在其他窗口中打开。没有剩余标签页时，启动器显示在最近记录下并选择 **无项目**。落到标签页后约半秒内，**⌘W** / **Ctrl+Shift+W** 和窗格的 **×** 不起作用，因此快速按第二次不会关闭刚落到的标签页；终端关闭时没有提示，且无法恢复。归档拆分标签页中的一个聊天后，其窗格保持为空。

每个窗格都是独立卡片：40 px 标题栏、圆角边框，卡片之间以及卡片与展开的侧边栏之间均为 6 px 间距。外侧留白保持 8 px，侧边栏收起时的左侧留白也为 8 px。标题栏左侧是运行时图标、带菜单箭头的名称和可用时的账户；右侧依次是状态、停止或恢复按钮、拆分按钮、拆分标签页中的最大化按钮和 ×。侧面板也是独立卡片；其开关位于窗格区域右上角。每个聊天或终端标签页分别保留侧面板的展开或收起状态、已打开的界面和当前显示的界面。展开或收起只影响当前标签页；新标签页采用最近一次展开或收起的选择，重启后各标签页也从该选择开始。面板、文件阅读区和文件树的宽度仍是共享设置。侧面板标题栏以标签显示你打开的界面（**信息** 和 **文件**）；点击标签即可切换，当前标签上的 **×** 会关闭它并显示它之前的标签。标签之后的 **+** 列出每个界面，已打开的带勾选标记，并标出其按键：点击一项，或在列表打开时按 **I** 或 **F**，即可打开或切换到该界面，按 Esc 关闭列表。每个界面只打开一次，“文件”保留自己的文件标签页。关闭所有标签后，面板显示 **打开一个界面**，并以相同的按键列出各界面，这些按键在该列表获得焦点时生效；新对话的面板打开时显示此列表，焦点留在聊天中。只有终端的标签页也有侧面板，其中只有“文件”标签，没有 **×** 和 **+**，开关、宽度和调整大小与聊天的侧面板相同；在聊天与终端拆分的标签页中，终端获得焦点时侧面板保持打开，并显示最近获得焦点的聊天。[“文件”视图](#在侧面板中浏览文件)显示项目的文件。

聊天运行时，点击标题栏右侧紧跟状态的 **停止对话（Stop chat）** 图标；停止后，在同一位置点击 **恢复对话（Resume chat）** 图标。按钮位置不随状态变化：较长的状态向左延伸；聊天启动或恢复期间没有生命周期按钮，其位置保持留空。状态仅显示当前状态。窄窗格会依次隐藏详细状态、截短名称、隐藏账户、隐藏状态文字并保留状态圆点；生命周期按钮和窗格按钮始终可见。停止的聊天显示居中的 **对话已停止（Chat stopped）** 卡片，只有 **恢复（Resume）** 按钮和当前快捷键；× 用于归档。较矮的窗格会先隐藏徽标、截短或隐藏说明，只有在恢复按钮仍无法放下时才隐藏标题。**⇧⌘X** / **Ctrl+Shift+X** 与 **⇧⌘R** / **Ctrl+Shift+R** 作用于焦点聊天。点击聊天名称或其箭头打开菜单：**重命名…（Rename…）**、**分叉对话（Fork chat）** 和 **置顶（Pin）**，标签页已置顶时显示 **取消置顶（Unpin）**。× 会归档聊天，仍在运行时先确认。双击名称可直接重命名。重命名在原位编辑名称：Enter 保存，Esc 取消。终端标题栏不显示状态，其菜单包含 **重命名…** 和 **置顶**。用 ×、关闭快捷键或侧边栏操作关闭终端时，即使命令仍在运行，也不会弹出确认；远程窗口同样如此。Shell 以任意退出码结束时都会关闭窗格；正常退出应用或更新后的终端恢复保持原样。

在拆分标签页中，用 **×** 或 **⌘W** / **Ctrl+Shift+W** 关闭焦点窗格后，键盘焦点会移到保留的窗格，无需点击即可继续输入。关闭未获得焦点的相邻窗格时，焦点仍留在原来的工作位置。如果关闭或归档尚未完成时切换到其他标签页或输入位置，完成后也会保留新的焦点。

## 在侧面板中浏览文件

打开“文件”或某个文件，包括从终端链接或 **⇧⌘O**（**Ctrl+Shift+O**）打开，只改变当前标签页的侧面板。切换标签页时，会恢复各自已打开的界面和当前显示的界面。

**文件** 视图以树形显示一个检出或文件夹及其 git 状态。项目中的聊天或终端打开自己的检出：其工作目录所在的工作树，或主检出；任务按自己的工作目录以同样方式打开。工作目录位于检出顶层之下时，会展开并标记为 `cwd`。在项目之外，视图会询问要显示哪个文件夹：输入路径并按 Return，点击文件夹按钮使用系统文件夹选择器，或选择你的项目或最近选择的文件夹。Runner 会为该聊天、终端或任务记住所选文件夹，切换标签页或重启后仍然保留。

标题栏显示检出名称，关联工作树带分支图标，并统计已更改的文件数。`git status` 运行期间显示 **正在读取状态…**，此时已可浏览树。已更改的文件带有彩色字母：**M** 已修改、**A** 已添加、**R** 已重命名、**U** 未跟踪、**!** 未合并。检出中的更改过多（超过 200,000 个文件）而无法全部标记时，树下方会说明。文件夹内有更改时显示圆点，已删除的文件不会列出。被 gitignore 忽略的条目会变暗，例如 `target/`，以及主检出中的 `.worktrees/`。磁盘上的文件变化时树会随之更新，并保留已展开的文件夹和选中项。在 git 仓库之外，树为普通文件树，没有字母和计数。图标来自 [设置 → 侧面板 → 文件](#设置侧面板) 中选择的图标主题，默认为 Catppuccin，跟随浅色和深色模式。

点击检出名称打开选择器：最上方是 **选择文件夹…**；然后是仓库的每个工作树及其分支和短提交号，主检出在最前；再往下，项目之外的聊天或终端会列出你的项目，最后是最近的文件夹。输入内容会筛选列表；输入从根目录或 `~` 开始的完整路径并按 Return，会以该路径为树的根。右键点击文件夹可选择 **从这里显示文件**、**复制路径** 和 **在访达中显示**，Windows 上为 **在资源管理器中显示**，Linux 上为 **打开所在文件夹**；文件提供后两项。

点击文件夹可展开或收起，点击文件可[在标签页中打开](#在侧面板中阅读文件)。树获得焦点时，↑ 和 ↓ 移动选中项，→ 展开文件夹或进入其中，← 收起文件夹或回到上一级，输入字母会跳到下一个以这些字母开头的条目。记住的文件夹不存在时，Runner 改为打开会话自己的检出。如果它也不存在了，例如任务的工作树被删除后，视图会显示 **此文件夹已不存在**，并提供项目的检出或选择器。运行在另一台电脑上的聊天、终端或任务会显示 **这里无法显示文件**。

## 在侧面板中阅读文件

在树中点击文件，会在文件上方的标签页中打开它；打开的每个文件都会保留自己的标签页，直到你关闭它。树获得焦点时，空格或 Return 打开选中的文件。已打开的文件会切换到它的标签页；切换标签页会在树中选中该文件，并展开其所在文件夹。当前标签页显示 ×，其他标签页在悬停时显示；已更改文件的标签页带有其状态字母。关闭最后一个标签页后回到空白视图。

选定文件夹后，文件视图会加宽侧面板：文件区域位于内侧，树移到外侧边缘。打开文件之前，文件区域列出检出中已更改的文件，点击即可打开；没有更改或文件夹不在 git 中时，显示一条简短提示。窗口放不下两者时，树占据面板，直到你打开文件。保持打开的文件也会让面板在其他界面上保持加宽。关闭“文件”标签后，面板恢复常规宽度；文件标签页会保留，再次打开“文件”时恢复。标签栏右侧的树按钮可隐藏或显示树，面板会按树的宽度增宽，而不会挤压文件。拖动面板边缘可调整文件宽度；拖动文件与树之间的分隔线可调整树的宽度：面板宽度不变，文件不会窄于面板的常规宽度。聊天，或任务及其终端抽屉，至少保留 420 px：窗口太窄时先收窄文件，直到面板的常规宽度，树保持自身宽度；之后聊天或任务才让出空间。树按钮开启时，树始终显示。加宽后的任务面板中，会话卡片每行显示两张。

按 **⇧⌘O**（**Ctrl+Shift+O**），或点击树标题栏中的搜索图标，可在聊天或任务中的任意位置按名称查找文件：侧面板关闭时会打开到文件视图，查找框显示在面板上方。它搜索当前文件夹下文件的名称和所在文件夹，跳过 git 忽略的内容。输入可筛选，用 ↑ 和 ↓ 选择，Return 打开，Esc 关闭。如果在设置中关闭了侧面板或文件视图，这个按键会交给终端。

标签页超出标签栏时，标签栏可横向滚动，边缘淡出，并出现一个带数量的列表按钮，列出每个打开的文件及其所在文件夹；点击即可切换。文件视图获得焦点时，⌃Tab 和 ⌃⇧Tab（Windows 和 Linux 上为 Ctrl+Tab 和 Ctrl+Shift+Tab）在文件标签页之间切换，⌘W（Ctrl+Shift+W）关闭当前标签页。焦点在其他位置或没有打开文件时，⌘W 照常关闭窗格。

文件为只读，带行号，使用 [设置 → 侧面板 → 文件](#设置侧面板) 中设置的字体和字号，默认与终端相同。二十多种常用语言的代码会高亮显示，包括 Rust、TypeScript 和 JavaScript、Python、Go、C 和 C++、C#、Java、Kotlin、Swift、Ruby、PHP、shell 脚本、JSON、TOML、YAML、HTML、CSS、SQL 和 Makefile，配色取自为浅色或深色模式选择的[终端配色](appearance.md#主题与配色)；其他文件以纯文本显示。大文件会先显示文本，稍后显示配色。长行横向滚动，从不换行。拖动可选中文本，双击单词可选中它，按 ⌘A（Ctrl+A）选中整个文件，按 ⌘C（Ctrl+C）复制；选区可以超出屏幕上可见的部分。⌘F（Ctrl+F）在文件上方打开查找栏，显示匹配数以及区分大小写和正则表达式开关；Return 和 ⇧Return 跳到下一个和上一个匹配，Esc 关闭查找栏。⌘ 点击（Ctrl 点击）某一行，会在你的编辑器中打开文件并定位到该行。文件在磁盘上变化时，视图会重新读取并保留位置。焦点位于文件、其查找栏或渲染后的页面时，⌘+ 和 ⌘−（Ctrl+= 和 Ctrl+−）只改变查看器的文字大小，每次 1 像素，范围 8 到 32 px。这就是 [设置 → 侧面板 → 文件](#设置侧面板) 中的 **字号**。焦点在其他位置（包括文件树）时，它们缩放整个应用。⌘0（Ctrl+0）在任何位置（包括查看器）都重置应用缩放。

Markdown 文件默认以渲染后的样式打开，除非设置中另有选择：标题、列表和任务列表、表格、引用、按代码高亮的代码块、链接，以及项目中的图片。文件中的 HTML 按原文显示。在页面上拖动可选中文本，按 ⌘C（Ctrl+C）复制。标签栏中的 `</>` 按钮可在高亮的源码与渲染结果之间切换；在渲染页面上按 ⌘F（Ctrl+F）会切换到源码进行查找。指向网页的链接会在浏览器中打开，指向所显示文件夹中其他文件的链接会在新标签页中打开该文件；指向该文件夹之外的链接不会执行任何操作。

标签栏右侧的打开方式控件显示文件将用哪个应用打开；点击它会在该应用中打开当前文件，并定位到可见的行。它的下拉箭头列出 Runner 在 PATH 中找到的编辑器（Zed、VS Code 和 Cursor 中的已安装者），然后是 **默认应用** 和 **在访达中显示**，Windows 上为 **在资源管理器中显示**，Linux 上为 **打开所在文件夹**。在下拉箭头中选择你的编辑器：所选编辑器就是该控件打开的应用；侧面板无法显示文件时，在终端中 ⌘ 点击路径也会改用它打开。

在终端中 ⌘ 点击（Windows 和 Linux 上为 Ctrl 点击）文件路径，可在这里打开它：在该聊天、终端标签页或任务的侧面板中，在标签页中打开并定位到路径所指的行，同时选中该行；已打开的文件会切换到它的标签页并滚动到该行。收起的面板会打开，“文件”标签若已关闭会重新打开并显示，面板像打开文件时一样加宽，终端保持焦点。前提是侧面板和“文件”视图已开启、会话运行在这台电脑上，且路径位于“文件”视图显示的文件夹内；引用了行号的 Markdown 文件会在该行显示源代码。其他路径在 **打开方式** 所选的编辑器中打开，URL 在浏览器中打开。悬停链接时会显示点击后在哪里打开。

二进制文件显示文件名和大小，并提供 **用默认应用打开**。超过 10 MB 的文件不会读取：显示其大小，并提供一个用控件所选应用打开的按钮。被 git 忽略的文件（例如日志和构建输出）不受监视，而是每隔几秒重新读取一次。标签页打开期间被删除的文件会保留最后读取的版本，变暗显示在提示已删除的横幅下，其标签页带有红色 **D**；**关闭标签页** 是唯一的操作。

## 设置侧面板

**设置 → 侧面板** 有两个页面。在 **面板** 页面关闭 **显示侧面板**，会在每个标签页隐藏侧面板及其开关；下方的开关保留各自的值，并变暗。**信息** 和 **文件** 各自标出其按键，决定 **+** 在每个聊天、终端标签页和任务中是否提供该界面；关闭其中一个会关闭它已打开的标签。只开启一个时，聊天只显示该界面的标签，没有 **×** 和 **+**；两个都关闭的聊天或终端标签页没有侧面板。关闭“文件”后，在终端中 ⌘ 点击（Ctrl 点击）路径会在你的编辑器中打开文件。任务始终把会话作为第一个标签，且无法关闭。

在 **文件** 页面，**文件图标** 选择文件树的图标：**Catppuccin**（跟随浅色和深色模式）、**Material** 或 **Minimal**。**字体** 设置代码和 Markdown 代码块的字体：**与终端相同**、内置的 JetBrains Mono，或电脑上安装的任意等宽字体，与 **设置 → 终端 → 字体** 中的列表相同。已保存但不再安装的字体会以 JetBrains Mono 显示，且仍保持选中。**字号**（8 到 32 px，与终端相同）在你更改之前跟随终端字号，渲染后的 Markdown 文本也随之缩放。**Markdown 文件打开为** 可选 **渲染** 或 **源码**；`</>` 按钮仍可让标签页在两者之间切换。

## 拆分与导航

使用 **⌘D** / **Ctrl+Shift+D** 向右拆分， **⇧⌘D** / **Alt+Shift+D** 向下拆分。在空窗格的启动器中搜索智能体或角色，选择 **终端** 启动 Shell，或从侧边栏选择聊天。在拆分标签页中，拖动窗格运行时图标前的六点拖柄可调整布局；布局选择器提供常用排列。点击窗格拆分按钮旁的最大化按钮，或对焦点窗格按 **⇧⌘↩** / **Ctrl+Shift+Enter**，该窗格会占满整个标签页，其他窗格在隐藏状态下继续运行。窗格最大化时同一按钮高亮显示，再次点击或按快捷键会按原尺寸恢复拆分。切换到该标签页的其他窗格（通过侧边栏、**⌘[** / **⌘]**（**Ctrl+[** / **Ctrl+]**）或跳转到需要关注的窗格）会先恢复拆分再聚焦该窗格；拆分最大化的窗格会先恢复拆分，关闭它则让标签页其余部分保持拆分。最大化状态不会保存：重新启动、重新连接和恢复的窗口都显示拆分布局。拆分数量受窗口可用空间限制。新窗口会根据打开时已保存的侧边栏宽度和缩放比例设置固定最小尺寸，并为侧边栏的固定控件留出足够高度。之后调整缩放或侧边栏宽度不会更新已打开窗口的最小尺寸。

使用 **⌘[** / **Ctrl+[** 和 **⌘]** / **Ctrl+]** 在窗格间移动焦点。 **⌘1–9** / **Ctrl+1–9** 选择对应的可见侧边栏行：两种视图中的标签页或任务。 **⇧⌘[** / **Ctrl+Shift+[** 和 **⇧⌘]** / **Ctrl+Shift+]** 在最近查看的页面间切换。

从 Finder 或文件资源管理器将文件拖到聊天窗格、任务抽屉终端或任务成员终端，会在提示处插入路径，并像粘贴文件一样加引号。文件悬停时终端高亮，放下后获得焦点；按 Return 前不会执行任何内容。

窗格中的程序（如 Neovim、Helix 或 tmux）可以通过 OSC 52 把文本复制到剪贴板，前提是有窗口在其当前标签页中显示该窗格；没有窗口显示的窗格（包括被最大化窗格遮住的窗格）发出的复制会被丢弃。在 Linux 上，复制到主选区（primary selection）的内容会写入主选区。超过 1 MiB 的复制会被忽略；在远程窗口中，文本会写入你正在使用的电脑。程序无法通过这种方式读取你的剪贴板。

拆分 Shell 时，Runner 跟随 Shell 报告的工作目录。在 macOS 上会为 zsh 与 bash 安装目录报告。Windows Shell 若没有自己的目录报告提示符，即使执行过 `cd`，拆分仍使用原启动目录。

## 在终端中查找

在聊天窗格、终端、任务成员终端或任务抽屉终端中按 **⌘F** / **Ctrl+Shift+F**，会在终端右上角打开查找栏；终端尺寸保持不变。终端中选中的文本会填入查询内容；查找栏已打开时再次按下快捷键会选中查询内容。每个窗格都有自己的查找栏，关闭前会保留其查询内容。Windows 和 Linux 上， **Ctrl+F** 仍会送入 Shell。

输入时会实时更新匹配项，范围包括输出及其回滚内容，也包括折行到下一行的文本。普通查询不区分大小写；打开 **Aa** 可区分大小写，打开 **.\*** 可使用正则表达式搜索。普通查询也会忽略组合附加符号、emoji 变体选择符和连接符，终端将它们与所修饰的字符存放在一起，因此选中或粘贴的分解形式 é、❤️ 或组合 emoji 都能找到。由 e 加组合重音构成的分解形式也会匹配普通的 e，而预组合的 é 仍只匹配自身；只含这类符号的查询视为空查询。正则表达式无法匹配这些符号本身。计数显示当前匹配项和总数，最多显示 1000+。无匹配时以红色显示 **无结果**，模式无效时显示 **正则表达式无效**，并保留上一次的匹配高亮，直到模式重新有效。所有可见匹配项以琥珀色淡色标出，当前匹配项为实心琥珀色。

匹配项从最新输出开始编号。Enter 或 **⌘G** / **F3** 移到下一个更早的匹配项，⇧Enter 或 **⇧⌘G** / **Shift+F3** 移到上一个更新的匹配项；到达两端时循环。只有匹配项不在屏幕上时终端才会滚动，并将其置于中间。查找栏打开期间，新输出会更新匹配项和计数，当前匹配项保持在原文本上；选中匹配项后，视图保持不动。

查找栏获得焦点时，Esc 关闭查找栏；点击终端使其获得焦点后，Esc 会送给程序。用 Esc 或 **×** 关闭会清除高亮，并将终端滚回打开查找前的位置；切换到其他标签页或任务，或从任务成员切换到其他成员或消息流时，查找也会以同样的方式关闭。切换成员时任务抽屉终端仍然显示，因此它的查找保持打开。使用备用屏幕的程序（例如 `less`、`vim` 或全屏智能体界面）在备用屏幕上没有回滚内容，因此查找只搜索可见屏幕，查找栏会提示这一点。

## 组织侧边栏

使用侧边栏右键菜单重命名和整理标签页、分组到文件夹，以及固定常用工作。聊天行的菜单依次为 **重命名…**、**分叉对话** 和 **置顶**，分隔线后是 **归档（Archive）**；拆分标签页的菜单为 **重命名标签页…**、**置顶** 和 **全部归档（Archive all）**，后者归档每个窗格；终端行的菜单为 **重命名…**、**置顶** 和 **关闭终端（Close terminal）**。[项目](../concepts/projects.md)按目录分组，文件夹则组织侧边栏条目。状态标记显示活动、需要关注和已停止会话。用它找到需要检查的终端，不要将空闲标记视为审查完成。

使用搜索旁的列表筛选按钮，或按 **⌘.** / **Ctrl+.**（**切换侧边栏视图**），在默认的 **项目（Projects）** 与 **活动（Active）** 之间切换。快捷键还会展开已收起的侧边栏。Runner 会记住选择。活动视图分为 **智能体（Agents）** 和 **终端（Terminals）** 两组，隐藏空分组并显示可见数量。智能体组同时包含聊天和任务，聊天与其关联任务组成与项目视图相同的关联分组；已结束的任务会留在分组中，直到你将其归档。点击智能体或终端标题可折叠或展开；折叠状态会被记住。活动视图包含运行中的聊天、终端和具有活动成员的任务，包括空闲智能体和 Shell。每组内按标签页与任务创建时间从早到晚排列，新工作加入末尾；状态变化、未读输出、重命名和重启不会移动行。第二行显示项目与相对目录，项目外工作则显示工作目录。重命名只改标题，位置仍保留。

活动视图与项目视图一样，每个标签页占一行。包含任意智能体窗格的标签页显示在智能体组；只有终端的标签页显示在终端组。拆分标签页使用拆分图标，名称默认来自第一个聊天或终端窗格，除非手动命名。选择行会打开需要关注的窗格；没有待关注项时打开上次获得焦点的窗格。任务成员汇总成一行。已停止的聊天或未关联任务只有存在未读输出或错误时才保留，已关联任务则留在分组中直到归档；仅被选中不会使行继续显示。已完成的未读回复保留到查看，错误保留到清除。所有运行中的终端均列出，包括空闲 Shell；终端退出后立即关闭。终端活动使用 Runner 现有的基于输出的忙碌估计，不包含抽屉终端。活动视图保留右键菜单；拖动和排序仍在项目视图中进行。

安装并启用 Codex、Claude Code 和 Antigravity CLI 后，页脚显示实时每周用量。Antigravity CLI 在页脚显示 **Gemini 模型（Gemini Models）** 每周模型池百分比，并在用量弹窗与 **设置 → 用量（Settings → Usage）** 中分别列出 **Gemini 模型（Gemini Models）** 与 **Claude 和 GPT 模型（Claude and GPT models）**。当启用的侧边栏徽章超出可用页脚宽度时，Runner 会保留用量最高的徽章并以紧凑的 `+N` 标记收起其余徽章；点击该区域仍可在用量面板查看全部已启用智能体。Antigravity CLI 用量检查需要 **1.5.8 或更新版本**：未登录的检查绝不会自动打开浏览器登录，而是提示在终端运行 `agy login`；未知或更低版本则会跳过登录检查，直接将 Antigravity CLI 用量保持为不可用。在 **设置 → 用量（Settings → Usage）** 中，可隐藏全部或单个智能体的徽章，选择 5、15、30 或 60 分钟检查间隔，并显示或隐藏 5 小时窗口。徽章开关上方的紧凑侧边栏预览跟随选择变化，使用与页脚相同的用量控件、主机按钮和设置齿轮。用量控件默认透明，悬停时才显示按钮背景。预览中的按钮不可操作；宽度不足时，示例移到标签下方。隐藏用量后，主机和设置按钮的位置保持不变。用量页始终显示每周限额；Claude Code 显示当前使用的账号。弹出面板中的设置按钮会打开此页。刷新失败或 Runner 重启时，会保留上次获取的用量及其更新时间；重启后，自那次获取以来已重置的限额不再显示。点击可打开用量面板，查看每个用量窗口及其重置时间。独立齿轮打开设置。Runner 有更新时会显示在名称旁。

Codex 还会在用量弹窗和「设置 → 用量」的限额下方单独显示「剩余额度」。显示余额时会四舍五入到整数额度，底层仍保留精确值；无限额度显示「无限」，缺少额度数据时显示「暂无数据」。隐藏 5 小时限额或未返回限额窗口时，额度仍然可见。刷新失败时会静默保留上次余额及其原始更新时间；限额重置时间不会使额度过期。侧栏百分比和接近限额通知仍以限额窗口为准。

**⌘K** / **Ctrl+Shift+P** 打开命令面板，查找聊天、任务、角色、小队和命令。 **⌘S** / **Ctrl+B** 切换侧边栏。

## 聊天下方的关联任务

智能体从聊天中启动的任务会关联到该聊天。在项目视图中，该聊天的标签页领起一个分组，关联线从聊天连到每个关联任务。每个任务行显示任务状态：需要你处理时显示举手图标，失败时显示警示图标，Runner 重启中断了某个成员的回合时显示琥珀色暂停图标，工作中显示加载图标，稳定下来且有未读输出时显示圆点。没有成员运行后，任务行与其他已停止的任务相同：灰色旗标，仅在有未读输出时显示圆点。每当任务变为需要处理、失败、已中断或稳定，聊天会收到一行简短的 `[runner]` 汇报，见[让智能体操作 Runner](drive-runner-from-agents.md#从-runner-聊天启动)。

点击聊天行上的折叠箭头，可把分组折叠为一行，显示其中任务数量及最紧急的状态，顺序为需要处理、失败、已中断、工作中、已稳定。Runner 会记住折叠的分组。活动视图中的折叠箭头作用相同，在任一视图中折叠分组，两个视图中都会折叠。在活动视图中，折叠后的行保持原有高度，用这一汇总代替文件夹行，并在末尾显示最紧急状态的图标；展开后文件夹行恢复。折叠分组中的任务没有数字快捷键。拖动或固定作用于整个分组：在关联任务上固定或取消固定，会固定或取消固定该聊天的标签页。在界面中归档带有未归档关联任务的聊天时会先请求确认，并将这些关联任务一并归档（若要保留某个任务，可先使用 **与 <聊天> 解除关联**；在命令行中使用不带 `--with-missions` 的 `runner session archive` 则只归档聊天）；归档单个任务会将其移出分组。

要手动关联任务，把任务行拖到智能体聊天行的中部，该行会显示 **关联到 <聊天>（Link to <chat>）**；行的顶部和底部仍显示常规的排序标记。放在分组的任务之间会把任务关联到该分组的聊天并放在该位置；标签页包含多个智能体聊天时会询问关联哪一个。任务菜单中有 **关联到聊天（Link to chat）**，这是一个带搜索框的子菜单，列出任务所属项目中的智能体聊天；任务已关联时还有 **与 <聊天> 解除关联（Unlink from <chat>）**。在活动视图中通过此菜单关联。只能关联未归档的智能体聊天，且它须与任务属于同一项目，或两者都不属于项目；已关联的任务再次关联时会改为新聊天。聊天会收到一行包含任务当前状态的 `[runner]` 汇报。

把关联任务拖出分组，放到项目的普通行之间即在该处解除关联；放到固定行之间则解除关联并固定。**与 <聊天> 解除关联** 会把任务放在分组正下方；如果分组已固定，则把任务放回其项目且不固定。最后一个任务离开后，分组解散，聊天保持原位。任务标题栏显示 **已关联 <聊天>（linked to <chat>）**，点击可打开该聊天；聊天已归档时显示 **已关联 <聊天>（已归档）**。显示另一台电脑的窗口会显示其分组；主机支持时，可用相同的菜单、选择器与拖动控制关联或解除关联任务。

## 使用另一个窗口

按 **⇧⌘N** / **Ctrl+Shift+N** 打开另一个 Runner 窗口。如果聊天或任务正由其他窗口控制，会显示 **在其他窗口中打开（Open in another window）** 覆盖层。使用交接控制聚焦原窗口或将内容移到这里。一个终端同时只属于一个窗口；覆盖层防止两个窗口发送冲突输入。

按 **⇧⌘W** / **Alt+F4** 关闭窗口。布局会保存，会话可以保持运行。Windows 关闭最后一个窗口时遵循 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 。macOS 上退出应用与关闭窗口是不同操作。

Windows 上，从开始菜单、快捷方式或任务栏再次启动已运行的 Runner，会将现有应用置前，而非启动第二份：主窗口已关闭则重新打开，已最小化则还原。Runner 正在退出时会等待其退出再启动；若 10 秒后仍在运行，则仍会启动另一份。开发版与已安装版是独立应用，可以并行运行。

**⌘W** / **Ctrl+Shift+W** 作用于焦点窗格或聊天标签页（焦点在任务抽屉时隐藏抽屉，或关闭启动器页面），不同于关闭整个窗口。明确要停止智能体时使用 **停止（Stop）** ，要将聊天移出活动列表时使用 **归档（Archive）** 。

后台通知在 **设置 → 通知（Settings → Notifications）** 中配置。聊天事件默认启用，任务事件需主动开启。**用量 → 接近限额（Usage → Near the limit）** 默认开启，阈值为 80%，可选择 50–90%。每个用量窗口每个重置周期提醒一次，涵盖 Codex、Claude Code 当前账号以及 Antigravity CLI 的两个模型池；隐藏 5 小时窗口后也不会对其提醒。点击用量通知打开设置 → 用量。只要用量提醒开启，隐藏徽章仍会继续检查；徽章和提醒均关闭时才停止定时检查。点击通知会打开对应聊天或任务。当前窗口显示另一台电脑时，本地通知仍可能出现；点击后会让一个窗口返回本机并打开本地条目。

所有默认快捷键与自定义方式见[键盘快捷键](../reference/keyboard-shortcuts.md)。

## 在另一台电脑上工作

登录后，从侧边栏选择电脑；登录方法见[远程访问](remote-access.md)。聊天创建、窗格拆分和调整大小、Shell 窗格、聊天生命周期与侧边栏组织都在主机上使用相同控制。远程任务使用相同消息流、回答卡片、收件人输入框、成员标签页和终端抽屉。启动器的小队步骤列出主机小队；创建或编辑小队需在主机完成。可用操作取决于主机版本。命令面板搜索该电脑的聊天与任务；角色和小队打开主机只读列表，并提供聊天与任务启动操作。创建、编辑、删除角色或小队，以及设置和已归档项目，需要返回本机后操作。

启动器使用主机的智能体和角色，并显示主机当前 Claude 账号。**更改** 打开主机的文件夹浏览器；本地窗口使用操作系统文件夹选择器。启动器为聊天和任务列出主机项目。启动器的最近记录跨项目和窗口共享，本机与每台远程主机分别保存。使用 ↑/↓ 和 Enter 选择搜索结果或固定条目；在默认页按 Esc 返回之前的标签页或页面；拆分窗格中按 Esc 清空搜索。返回本机会还原本机标签页、选择和侧边栏状态。

## 后台任务

智能体更新在后台运行，窗口仍可正常使用。右下角胶囊显示优先级最高的任务，并标出其他任务的数量。点击可打开任务列表，查看版本、最新输出步骤、进度与操作。优先级依次为：可能需要输入、失败、运行中、已完成。

胶囊上的 **×** 会隐藏它，任务继续运行。任务可能需要输入或失败时，胶囊重新出现；成功不会让它重新出现。选择 **回答（Answer）** 或 **显示输出（Show output）** 才会打开该任务的终端对话框。对话框不会自动打开，因此正在聊天中输入的文字仍留在原聊天。**隐藏（Hide）**、Escape 与对话框关闭按钮都让安装程序继续运行。

停止运行中的任务会中断安装程序并检查可执行文件。仍能启动时移除该行；损坏时保留 **重新安装（Reinstall）**。失败任务保留 **重试（Retry）**、**显示输出（Show output）** 与关闭操作。所有任务成功后，结果保留五秒，再自动清除胶囊与已完成行。现有智能体聊天继续使用旧版本，直到重新启动。

胶囊与列表属于当前电脑。远程电脑的更新恢复保留在远程窗格中，不会加入本地列表。任务是临时状态，会在 Runner 后台服务重启后消失。
