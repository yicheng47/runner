# 聊天、标签页与窗口

将独立会话排列为拆分标签页，在侧边栏组织工作，并使用多个窗口，同时明确当前控制的是哪个终端。

## 认识三个层级

| 层级 | 承载的内容 |
| --- | --- |
| 窗口 | 真实的操作系统窗口 |
| 标签页 | 一组窗格，在项目侧边栏中对应一个条目 |
| 窗格 | 承载单个聊天或 Shell 会话的槽位 |

**⌘N** / **Ctrl+N** 在工作区显示启动器页面，并选中侧边栏导航中的 **新建聊天**。只有启动聊天、终端或任务后，才创建标签页和项目树条目。该页面没有窗格标题栏、拆分菜单或 ×；每个步骤上方都保留 Runner 标志和“开始新工作”。在默认页按 Esc 返回之前的标签页，选择任意侧边栏条目也会离开启动器。**⌘T** / **Ctrl+Shift+T** 在可用空窗格或新标签页中启动 Shell。智能体需要共享消息流时，请使用[任务](../concepts/missions.md)。

每个窗格都是独立卡片：40 px 标题栏、圆角边框，卡片之间以及卡片与展开的侧边栏之间均为 6 px 间距。外侧留白保持 8 px，侧边栏收起时的左侧留白也为 8 px。标题栏包含运行时、名称、可用时的账户、状态、菜单、拆分按钮和 ×。侧面板也是独立卡片；其开关位于窗格区域右上角，Shell 获得焦点时隐藏。

聊天运行时，点击标题栏右侧、菜单之前的 **停止对话（Stop chat）** 图标；停止后，点击 **恢复对话（Resume chat）** 图标。按钮始终可见，位置不随状态变化；状态仅显示当前状态。启动和恢复过程中没有生命周期按钮。窄窗格会依次隐藏详细状态、截短名称、隐藏状态文字；操作按钮始终可见。停止的聊天显示居中的 **对话已停止（Chat stopped）** 卡片，只有 **恢复（Resume）** 按钮和当前快捷键；× 用于归档。较矮的窗格会先隐藏徽标、截短或隐藏说明，只有在恢复按钮仍无法放下时才隐藏标题。**⇧⌘X** / **Ctrl+Shift+X** 与 **⇧⌘R** / **Ctrl+Shift+R** 作用于焦点聊天。菜单提供停止或恢复、派生对话、重命名；× 会归档聊天，仍在运行时先确认。终端菜单只有重命名。用 ×、关闭快捷键或侧边栏操作关闭终端时，即使命令仍在运行，也不会弹出确认；远程窗口同样如此。Shell 以任意退出码结束时都会关闭窗格；正常退出应用或更新后的终端恢复保持原样。

## 拆分与导航

使用 **⌘D** / **Ctrl+D** 向右拆分， **⇧⌘D** / **Ctrl+Shift+D** 向下拆分。在空窗格的启动器中搜索智能体或角色，选择 **终端** 启动 Shell，或从侧边栏选择聊天。在拆分标签页中，拖动窗格运行时图标前的六点拖柄可调整布局；布局选择器提供常用排列。拆分数量受窗口可用空间限制。新窗口会根据打开时已保存的侧边栏宽度和缩放比例设置固定最小尺寸，并为侧边栏的固定控件留出足够高度。之后调整缩放或侧边栏宽度不会更新已打开窗口的最小尺寸。

使用 **⌘[** / **Ctrl+[** 和 **⌘]** / **Ctrl+]** 在窗格间移动焦点。 **⌘1–9** / **Ctrl+1–9** 选择对应的可见侧边栏行：两种视图中的标签页或任务。 **⇧⌘[** / **Ctrl+Shift+[** 和 **⇧⌘]** / **Ctrl+Shift+]** 在最近查看的页面间切换。

从 Finder 或文件资源管理器将文件拖到聊天窗格、任务抽屉终端或任务成员终端，会在提示处插入路径，并像粘贴文件一样加引号。文件悬停时终端高亮，放下后获得焦点；按 Return 前不会执行任何内容。

拆分 Shell 时，Runner 跟随 Shell 报告的工作目录。在 macOS 上会为 zsh 与 bash 安装目录报告。Windows Shell 若没有自己的目录报告提示符，即使执行过 `cd`，拆分仍使用原启动目录。

## 组织侧边栏

使用侧边栏右键菜单重命名和整理标签页、分组到文件夹，以及固定常用工作。[项目](../concepts/projects.md)按目录分组，文件夹则组织侧边栏条目。状态标记显示活动、需要关注和已停止会话。用它找到需要检查的终端，不要将空闲标记视为审查完成。

使用搜索旁的列表筛选按钮，在默认的 **项目（Projects）** 与 **活动（Active）** 之间切换。Runner 会记住选择。活动视图按 **聊天 → 任务 → 终端（Chats → Missions → Terminals）** 排列，隐藏空分组并显示可见数量。点击分组标题折叠或展开；折叠状态会被记住。活动视图包含运行中的聊天、终端和具有活动成员的任务，包括空闲智能体和 Shell。每组内按标签页与任务创建时间从早到晚排列，新工作加入末尾；状态变化、未读输出、重命名和重启不会移动行。第二行显示项目与相对目录，项目外工作则显示工作目录。重命名只改标题，位置仍保留。

活动视图与项目视图一样，每个标签页占一行。包含任意智能体窗格的标签页显示在聊天组；只有终端的标签页显示在终端组。拆分标签页使用拆分图标，名称默认来自第一个聊天或终端窗格，除非手动命名。选择行会打开需要关注的窗格；没有待关注项时打开上次获得焦点的窗格。任务成员汇总成一行。已停止聊天或任务只有存在未读输出或错误时才保留；仅被选中不会使其继续显示。已完成的未读回复保留到查看，错误保留到清除。所有运行中的终端均列出，包括空闲 Shell；终端退出后立即关闭。终端活动使用 Runner 现有的基于输出的忙碌估计，不包含抽屉终端。活动视图保留右键菜单；拖动和排序仍在项目视图中进行。

安装并启用 Codex 和 Claude 后，页脚显示实时每周用量。点击可打开用量面板，查看其他受支持提供商。只有其他用量提供商时，会显示 **用量（Usage）** 标签以便打开。独立齿轮打开设置。Runner 有更新时会显示在名称旁。

**⌘K** / **Ctrl+K** 打开命令面板，查找聊天、任务、角色、小队和命令。 **⌘S** / **Ctrl+S** 切换侧边栏。

## 使用另一个窗口

按 **⇧⌘N** / **Ctrl+Shift+N** 打开另一个 Runner 窗口。如果聊天或任务正由其他窗口控制，会显示 **在其他窗口中打开（Open in another window）** 覆盖层。使用交接控制聚焦原窗口或将内容移到这里。一个终端同时只属于一个窗口；覆盖层防止两个窗口发送冲突输入。

按 **⇧⌘W** / **Alt+F4** 关闭窗口。布局会保存，会话可以保持运行。Windows 关闭最后一个窗口时遵循 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 。macOS 上退出应用与关闭窗口是不同操作。

Windows 上，从开始菜单、快捷方式或任务栏再次启动已运行的 Runner，会将现有应用置前，而非启动第二份：主窗口已关闭则重新打开，已最小化则还原。Runner 正在退出时会等待其退出再启动；若 10 秒后仍在运行，则仍会启动另一份。开发版与已安装版是独立应用，可以并行运行。

**⌘W** / **Ctrl+Shift+W** 作用于焦点窗格或聊天标签页（焦点在任务抽屉时隐藏抽屉），不同于关闭整个窗口。明确要停止智能体时使用 **停止（Stop）** ，要将聊天移出活动列表时使用 **归档（Archive）** 。

后台通知在 **设置 → 通知（Settings → Notifications）** 中配置。聊天事件默认启用，任务事件需主动开启。点击通知会打开对应聊天或任务。当前窗口显示另一台电脑时，本地通知仍可能出现；点击后会让一个窗口返回本机并打开本地条目。

所有默认快捷键与自定义方式见[键盘快捷键](../reference/keyboard-shortcuts.md)。

## 在另一台电脑上工作

登录后，从侧边栏选择电脑；登录方法见[远程访问](remote-access.md)。聊天创建、窗格拆分和调整大小、Shell 窗格、聊天生命周期与侧边栏组织都在主机上使用相同控制。远程任务使用相同消息流、回答卡片、收件人输入框、成员标签页和终端抽屉。启动器的小队步骤列出主机小队；创建或编辑小队需在主机完成。可用操作取决于主机版本。命令面板搜索该电脑的聊天与任务；角色和小队打开主机只读列表，并提供聊天与任务启动操作。创建、编辑、删除角色或小队，以及设置和已归档项目，需要返回本机后操作。

新建聊天使用主机的智能体和角色，并显示主机当前 Claude 账号。**更改** 打开主机的文件夹浏览器；本地窗口使用操作系统文件夹选择器。启动器为聊天和任务列出主机项目。启动器的最近记录跨项目和窗口共享，本机与每台远程主机分别保存。使用 ↑/↓ 和 Enter 选择搜索结果或固定条目；在默认页按 Esc 返回之前的标签页或页面；拆分窗格中按 Esc 清空搜索。返回本机会还原本机标签页、选择和侧边栏状态。
