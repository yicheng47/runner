# 小队

小队是可复用的角色团队，由具名成员槽位和共享团队约定组成。启动小队会创建任务，每个槽位各有一个终端。

列表默认每页显示 10 个小队。使用页脚的 **10 / 页（10 / page）** 选择 10、25 或 50；Runner 会分别记住小队和角色列表的设置。更改每页数量会保留搜索条件并返回第 1 页。长页面可以滚动，列标题和页脚保持可见。

## 成员槽位

每个槽位选择一个角色，并指定代号，例如 `coder` 或 `reviewer`。成员发送消息时使用这些代号。即使两个槽位使用同一个已保存角色，队内代号也必须唯一。

可启动的小队至少有一个槽位。每个成员都会收到任务目标；角色提示词与团队约定负责说明谁先行动，以及如何交接工作。

小队页面可以调整槽位顺序，并覆盖单个槽位的智能体、模型、推理强度或 Codex 速度。继承值来自角色，并受所选运行时能力的限制。

## 团队约定

团队约定是在任务中附加给每个成员的共享指令。用它明确谁编辑、谁审查、何时交接、必须执行哪些检查，以及是否允许提交或其他外部操作。角色启动直接聊天时不使用团队约定。

例如，默认结对组合要求 coder 在功能分支上实现，reviewer 检查工作区差异，双方反复审查直到通过。除非目标明确授权 Git 操作，否则默认约定要求保留未提交的修改。

## 小队与任务的区别

小队是可复用的初始配置。[任务](missions.md)拥有实际运行的工作、目标、消息流与成员。在任务中添加或移除成员不会编辑已保存的小队。也可以作为 **空任务（Empty mission）** 启动，再逐个添加成员。

请按[组建小队](../guides/build-a-crew.md)创建自己的团队。
