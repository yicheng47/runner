# 项目

项目为工作目录赋予名称，并在侧边栏中组织该目录下的聊天和任务。这样就不用每次启动时重复选择同一个文件夹。

侧边栏默认显示项目。搜索旁的列表筛选按钮可切换到活动视图，汇总各项目中运行的聊天与终端、具有活动成员的任务，以及需要关注的工作；切换视图不会改变项目组织方式。

从侧边栏创建项目并选择目录。在该项目中启动的新聊天和任务会使用此目录。启动时仍可另行指定工作目录。

**⌘N** / **Ctrl+N** 和 **新建标签页** 打开的启动器页面，在可编辑的选择器中预选最近标签页的项目，并使用该项目的文件夹，聊天、终端和任务均如此。页面已显示时，使用打开页面时所在标签页的项目；若该标签页已不存在，则使用最近查看的标签页。最近记录中的标签页或没有标签页时，选择 **无项目**；最近记录旁的 **+** 始终以 **无项目** 开始。虚线条目仍在最近记录下，侧边栏不会选中或展开预选的项目。远程电脑使用各自的标签页和项目。**⇧⌘M** / **Ctrl+Shift+M** 和从小队启动时使用当前活动项目。项目的 **+** 显示锁定到该项目的启动器页面，项目已折叠时会将其展开：选择器被禁用，用 **更改** 选择的文件夹仍归入该项目。页面打开期间若该项目被删除，页面回到 **无项目** 并解除锁定。启动器显示期间，虚线的 **新建标签页** 条目位于打开它的项目下，其他情况位于最近记录下。之后无论选择器或 **更改** 如何变化，条目都不移动，启动的内容归入选择器显示的项目。该条目不是已保存的标签页：启动后会被新标签页的条目替换，离开启动器时会消失。拆分标签页中的真实空窗格没有项目和文件夹控件：聊天沿用标签页的项目与相邻会话的目录，× 用于关闭该窗格。

选择项目会使用项目文件夹；若当前目录已在其中（例如工作树），则保留当前目录。**无项目** 保留当前文件夹。在未锁定的页面上，选择其他项目中的目录时，会跟随最深匹配的项目。角色有自己的工作目录时优先使用它，除非你明确使用 **更改** 选择了文件夹。任务成员在启动器的文件夹中启动。选择项目或按 Esc 关闭项目菜单后，焦点返回启动器的搜索框，↑/↓ 可继续在条目间移动。

CLI 也能创建相同的关联：

```sh
runner project create "My app" --path /absolute/path/to/my-app
runner chat start --runtime codex --project "My app"
runner mission start --crew "Pair coding crew" --project "My app" --title "README review" --goal "Review the README for accuracy."
```

Windows 上请使用绝对 Windows 路径，例如 `C:\Users\you\src\my-app`。包含空格的路径要加引号。

## 目录与分组

在 Shell 中，从已注册项目的目录内启动聊天或任务，会自动关联到该项目。`--project` 显式选择项目及其目录；`--cwd` 则直接指定启动目录。这两个参数不能同时使用。CLI 的目录默认为 Shell 当前目录，因此启动任务前请确认所在位置。

项目只是目录关联，并非沙箱或隔离的 Git 检出。多个会话可以编辑相同文件。若要在独立 worktree 中工作，请先创建 worktree，再从其路径启动。

将现有任务移动到另一个项目只改变侧边栏分组；不会移动仓库文件，也不会更改运行中进程的目录。

## 移除项目

删除项目会归档其成员，不会删除磁盘目录。若仍有成员运行，CLI 会拒绝删除，除非提供 `--force`。删除分组前请先停止并检查受影响的工作。

项目命令见 [CLI 参考](../reference/cli.md#runner-project)。
