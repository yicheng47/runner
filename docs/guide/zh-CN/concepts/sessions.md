# 会话

会话是在真实终端中运行的单个智能体或 Shell。直接聊天有自己的会话；任务中每个活动成员也各有一个会话。

运行时提供自己的终端界面、认证、命令和对话历史。Runner 承载终端、跟踪状态，并记录恢复所需的对话标识。[角色](roles.md)是模板，会话是一次具体运行。

## 识别状态

工作中与空闲指示器帮助你找到活动智能体。支持的运行时通过钩子报告这些状态；其他运行时以终端活动作为基础判断。空闲并不证明任务通过了检查。部分运行时还会报告需要批准或回答的状态；差异见[支持的智能体](../reference/supported-agents.md)。

已停止或崩溃的会话没有可接收输入的智能体进程。选择下一步前请阅读终端和错误信息。

## 打开终端链接

将指针悬停在 URL 或文件路径上可高亮链接，然后在 macOS 上按住 ⌘ 或 Ctrl 点击，在 Windows 上按住 Ctrl 点击。Web URL（`http://` 与 `https://`）会在浏览器中打开。本地 `file://` URL（纯文本或终端超链接，指向本机或 `localhost`，例如 Windows 上的 `file:///C:/...`）和文件路径——包括 Windows 盘符路径（`C:\...` 与 `C:/...`）、UNC 路径（`\\server\share\...`）以及 `:line[:column]`、`(line,column)` 或 `#Lline` 后缀——位于侧面板“文件”视图显示的文件夹内时，会在侧面板的标签页中打开并定位到该行，否则在 **打开方式** 所选的编辑器中打开；见[在侧面板中阅读文件](../guides/chats-and-windows.md#在侧面板中阅读文件)。

当运行时将带下划线的 URL 换行到缩进行，或将超链接放在表格单元格中时，悬停任一片段都会高亮完整链接；按住修饰键点击任一片段都会打开同一目标。重新打开会话后链接仍可使用。

## 选择合适的操作

| 操作 | 效果 |
| --- | --- |
| 停止（Stop） | 结束进程，保留会话以便恢复 |
| 恢复（Resume） | 在运行时支持时继续已停止智能体记录的对话 |
| 重启任务成员（Restart） | 为该成员开始全新对话 |
| 分叉聊天（Fork） | 在支持分叉的运行时中，从当前对话创建另一条聊天 |
| 归档聊天（Archive） | 停止聊天并从活动列表移除；可在设置 → 已归档中找到 |

归档会保留智能体已保存的对话和历史。在 **设置 → 已归档** 中还原聊天，再恢复运行，即可在全新的终端中继续原来的对话。

Shell 没有停止、恢复或重启控制。用 Ctrl+C 中断命令。关闭终端，或让 Shell 以任意退出码结束，都会关闭窗格而非归档。无论本地还是远程，终端窗格 ×、关闭快捷键、侧边栏关闭终端及任务抽屉 Shell 关闭都会立即执行，不弹确认，即使命令仍在运行。归档聊天仍需确认，全部归档仍显示聊天和终端数量。关闭窗口会保存布局，并可让会话保持运行。

## Claude Code 账号

配置了多个 [Claude Code 账号](../guides/claude-accounts.md)时，新会话和恢复会使用当前账号。运行中的会话继续使用原账号。暂停的聊天会标明先前账号与当前账号；恢复会继续原始对话记录，分叉则在当前账号下保存新对话。显式设置的 `CLAUDE_CONFIG_DIR` 环境变量优先。

## 退出、重新启动与恢复

Runner 的后台服务 `runnerd` 独立于应用窗口管理进程。 **设置 → 通用 → 退出 Runner 时（Settings → General → When Runner quits）** 提供 **每次询问（Ask）** 、 **保持运行（Keep running）** 和 **停止会话（Stop sessions）** 。选择保持运行后，重新打开应用会连接到仍在运行的终端。

若进程因关机或更新而停止， **启动时恢复运行中的智能体（Resume running agents on launch）** 控制自动恢复。手动停止的聊天保持停止，直到你恢复它们。正常退出或更新时停止的终端窗格会自动恢复，不受智能体恢复设置影响。恢复依赖智能体保存的对话标识和历史；仅靠终端画面无法还原未保存的对话。

如果智能体在恢复时退出，Runner 会保留它的对话，再次点击恢复会重试同一对话。只有当运行时保存的对话已不存在时，Runner 才会开始新对话。对于 Codex，如果记录的对话已不存在，但聊天最初的对话仍在磁盘上，Runner 会改为恢复最初的对话。

如果守护进程崩溃，Runner 会重新连接并为受影响聊天提供恢复；没有正常退出恢复标记的 Shell 会关闭窗格。反复出现故障时，使用 **设置 → 关于 → 打开日志文件夹（Settings → About → Open log folder）** （macOS 上为 **在访达中显示日志（Reveal logs in Finder）** ）。对话丢失或启动失败时，请参阅[故障排查](../guides/troubleshooting.md)。
