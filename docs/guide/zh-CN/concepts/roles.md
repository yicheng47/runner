# 角色

角色是可在聊天和小队中复用的智能体配置。它描述智能体应如何工作；启动角色会创建一个独立会话。

## 角色保存的内容

| 设置 | 用途 |
| --- | --- |
| 名称与代号 | 可读名称和唯一标识符，例如 `coder` |
| 智能体运行时 | 要运行的 CLI，例如 Codex 或 Claude Code |
| 模型与推理强度 | 运行时支持的可选设置；否则使用其默认值 |
| 速度 | Codex 的继承、标准或快速服务等级 |
| 系统提示词 | 角色的职责和工作方式 |
| 工作目录 | 启动时未指定目录时使用的默认文件夹 |
| 命令与环境变量 | 智能体进程的启动方式 |

在 **角色（Roles）** 中创建和编辑角色。系统提示词应描述它的职责，例如“检查差异并报告缺陷，不要编辑文件”。将具体任务写在聊天提示或任务目标中，使角色保持可复用。

列表默认每页显示 10 个角色。使用页脚的 **10 / 页（10 / page）** 选择 10、25 或 50；Runner 会分别记住角色和小队列表的设置。更改每页数量会保留搜索条件并返回第 1 页。长页面可以滚动，列标题和页脚保持可见。

## 聊天和小队中的角色

在聊天启动器中搜索已保存的角色，点击或按 Enter，即可使用角色保存的运行时、模型、推理强度、速度和指令启动。智能体条目不使用角色，沿用智能体自身配置。角色页的 **聊天** 操作直接启动，并更新同一台电脑的最近记录。已保存的设置在角色页修改；聊天启动时不命名，需要时可从窗格菜单重命名。

[小队成员槽位](crews.md)引用角色，并为其指定队内代号。同一个角色可以填入多个槽位，各自使用不同代号。槽位可以覆盖运行时、模型、推理强度和 Codex 速度。更改运行时会先将引擎特定设置重置为新运行时的默认值，再应用覆盖值。

编辑角色不会向已运行的终端输入指令。需要立即发出指令时请发送消息；启动新工作时请检查启动设置。

[组建小队](../guides/build-a-crew.md)提供了完整的 coder/reviewer 示例；角色命令见 [CLI 参考](../reference/cli.md#runner-role)。
