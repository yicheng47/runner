## Product boundaries

`runnerd` owns local state and sessions; the desktop and CLI are clients. Remote access adds another authorized client to those same sessions. Session traffic is encrypted end to end between the host and client; the relay cannot read it. The public repository owns host behavior and the client protocol, while the web service and native phone app are developed separately. Remote control shipped in 0.18.0 through the hosted relay; the `nightly-remote` umbrella and its `remote-nightly` channel are retired.

The companion protocol is versioned independently of the local client protocol. A rejected remote client leaves the daemon and agents running. Local application updates retain their existing restart-and-resume contract; remote version negotiation must not reuse the local daemon replacement path.

Runner's own MCP server was removed in 0.11 and the CLI moved to runnerd's client protocol in 0.13.1. Mission coordination stays on the bundled `runner` CLI; Settings → MCP manages the user's servers. pi supports MCP natively as of 1.4.0, reading `~/.pi/agent/mcp.json` and `.pi/mcp.json` and managed with `pi mcp add` (checked 2026-11-02); [#764](https://github.com/yicheng47/runner/issues/764) builds on that and must not restore Runner MCP registration.

New runtimes follow the [integration checklist](./arch/runtime-integration.md). Automated checks and native platform verification remain separate evidence: the [OpenCode record](./tests/archive/592-opencode-runtime.md) and [Antigravity record](./tests/archive/747-antigravity-followups.md) retain their Windows and inference-dependent gaps.

## Backlog

Backlog issues have no release commitment and carry the `backlog` label. The Scheduling sections of the `feature` and `bug` skills call for a milestone or `backlog` on every open issue. The [backlog filter](https://github.com/yicheng47/runner/issues?q=is%3Aissue%20state%3Aopen%20label%3Abacklog) is the live list, 66 issues on 2026-11-28; their issues own scope and priority, and a fresh implementation spec is written when work starts.
