# Feature specs

Specs of features in development. A feature is filed as an issue only; its spec is written when development starts, on the feature's branch, and lands in the same pull request as the code. At a release sweep, default to deleting completed specs. Retain only major features or consequential migration/compatibility records under the [archive policy](../README.md#archive-policy), preserving unique current decisions and fixing references before pruning. Priorities and milestones live on the issues; [`../roadmap.md`](../roadmap.md) mirrors them.

Since 2026-09-01 a spec's number **is** its tracking issue number: file the issue first, then name the spec after it, so gaps in the sequence belong to bugs and PRs. Specs 01–64 predate the alignment and keep their numbers in `archive/`; the then-active ones were renumbered to their issues (05→73, 58→393, 61→403), and 60 (fork a chat) kept its number and shipped 2026-09-01.

## Active

- [748 — Link a chat to the missions it starts](./748-mission-link.md) — Runner records the chat that starts a mission, groups the mission with that chat in the sidebar and types a one-line report into the chat when the mission needs the person, fails or settles, so the agent no longer watches the feed; draft spec, design before implementation ([#748](https://github.com/yicheng47/runner/issues/748)).
- [634 — File preview and code review](./634-file-preview-and-review.md) — a project tree, read-only file/diff tabs, a base picker and review comments returned to the agent; design before implementation ([#634](https://github.com/yicheng47/runner/issues/634)).
- [931 — Installed terminal fonts](./931-installed-terminal-fonts.md) — the terminal's Font family lists every installed monospace font, searchable, beside the bundled JetBrains Mono; #634's file viewer reuses the list ([#931](https://github.com/yicheng47/runner/issues/931)).
- [559 — Command palette](./559-command-palette.md) — command mode over the existing keymap and quick-switcher overlay ([#559](https://github.com/yicheng47/runner/issues/559)).

0.19.0 shipped pane islands ([#1086](https://github.com/yicheng47/runner/issues/1086)), whose spec is retained in the [archive](archive/1086-pane-islands.md), and the launcher ([#1092](https://github.com/yicheng47/runner/issues/1092)), idle-only inbox delivery ([#1046](https://github.com/yicheng47/runner/issues/1046)) and host PIN setup ([#1044](https://github.com/yicheng47/runner/issues/1044)), whose specs are deleted; the [guide](../guide/README.md), the [delivery walkthrough](../tech/mission-message-delivery.md) and their validation records hold the current behavior.

0.19.1 shipped the mission launcher ([#1097](https://github.com/yicheng47/runner/issues/1097)), recovery from a submit that starts no turn ([#1102](https://github.com/yicheng47/runner/issues/1102)) and mid-turn delivery to Claude Code ([#1103](https://github.com/yicheng47/runner/issues/1103)). Their specs are deleted and remain at a fixed revision ([1097](https://github.com/yicheng47/runner/blob/5e437b517f4d7e2ad81a3a8d2bdf19372f044573/docs/features/1097-mission-launcher.md), [1103](https://github.com/yicheng47/runner/blob/5e437b517f4d7e2ad81a3a8d2bdf19372f044573/docs/features/1103-mid-turn-delivery.md)); the guide, the [delivery walkthrough](../tech/mission-message-delivery.md) and their validation records hold the current behavior. #1103's open question, a Settings override for mid-turn delivery, is [#1108](https://github.com/yicheng47/runner/issues/1108).

Linux support ([#823](https://github.com/yicheng47/runner/issues/823)) shipped as a beta in 0.18.2 and its issue is closed. The [platform contract](archive/823-linux-support.md), [signed-update contract](archive/823-linux-updates.md) and [OSC 7501 protocol contract](archive/861-program-status.md) are retained in the archive; native Linux acceptance gaps remain explicit in [the architecture](../arch/linux.md) and validation records. The [Linux brief](../impls/briefs/823-linux.md) stays as the large example.

Future work, including [iOS follow-through](https://github.com/yicheng47/runner/issues/912), [shell/agent separation](https://github.com/yicheng47/runner/issues/795) and [pi MCP management](https://github.com/yicheng47/runner/issues/764), stays in its issue until development starts. ## Archive

The [archive README](archive/README.md) indexes only important features and consequential decisions, with a retention reason for each topic. Completed small-feature and bug-fix specs are deleted under the [archive policy](../README.md#archive-policy); git history keeps their original text. Release contents and dates belong in the [roadmap](../roadmap.md), and validation evidence remains in [tests](../tests/README.md).
