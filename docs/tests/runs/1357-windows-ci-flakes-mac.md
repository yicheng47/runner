## Implemented changes

- `crates/runner-core/src/app_paths.rs`: Added `check_existing_dir` and `is_existing_dir`. On Windows, probes an open directory handle (`FILE_FLAG_BACKUP_SEMANTICS`, `access_mode(0)`) via `GetFileInformationByHandleEx(FileStandardInfo)` and on `ERROR_ACCESS_DENIED` inspects `RtlGetLastNtStatus()` (`CreateFileW`) so `STATUS_DELETE_PENDING` returns `Ok(false)` while genuine permission/access failures remain `Err`.
- `crates/runner-daemon/src/files/{fs.rs,git.rs,mod.rs,root.rs,watch.rs}`: Switched folder liveness checks to `is_existing_dir` / `check_existing_dir` (preserving inaccessible saved roots on `Err`) and added `Watch::unwatch_missing_root` / `Watch::mark_root_missing` to release OS directory handles and emit `FILES_CHANGED_EVENT` once when the watched root is gone.
- `crates/runner-app/src/surfaces/changes/mod.rs`: Switched missing-root checks in `apply_outcome`, `sync_watch`, and `recover_from_root_error` to `is_existing_dir` and called `self.unwatch(cx)` before `self.resolve(cx)` on root-missing recovery.
- `crates/runner-app/src/surfaces/files/{highlight.rs,markdown.rs}`: Added `PartialEq`/`Eq` on `Highlights`, `Page::matches_text`, and `Page::same_rendered`. `MarkdownView::set_page` skips work only when full rendered rows and decoded images match; otherwise it installs and lays out the new page while preserving `self.selection` when `Page::matches_text` holds.
- `docs/guide/guides/chats-and-windows.md` and `docs/guide/zh-CN/guides/chats-and-windows.md`: Documented that rendered Markdown reloads keep active selections when rendered text remains unchanged and clear invalid selections when text changes.
- Tests added/updated in `app_paths.rs` (including Windows-only tests for legacy `SetFileInformationByHandle(FileDispositionInfo)` `STATUS_DELETE_PENDING`, `remove_dir_all` with a held handle, and `icacls` `PermissionDenied`), `files/root.rs` (Windows `icacls` saved-root preservation), `files/tests.rs` (daemon `removing_watched_root_emits_changed_and_marks_root_missing`, plus `an_unchanged_change_event_during_markdown_drag_preserves_selection_and_copy` and `a_link_target_or_formatting_edit_updates_page_while_preserving_selection`), and `changes/tests.rs` (`removing_root_after_load_transitions_to_missing_when_shown_or_reopened` updated to pre-subscribe before `h.show`, prove initial `FILES_STATUS_EVENT` and accumulate both `.watch-ready` `FILES_CHANGED_EVENT` and `.watch-ready`-containing `FILES_STATUS_EVENT` in either order with no unconditional sleep, remove `wt-live` without synthetic event injection, and assert real `FILES_CHANGED_EVENT` + unwatch).
