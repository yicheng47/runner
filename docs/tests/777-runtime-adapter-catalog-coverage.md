## CI follow-up

The first PR run (`37023214994`) failed on Windows because a Unix-only model-test import was unconditional and two test-helper import groups followed their test modules. Those imports are now gated or inside the modules that use them. macOS formatting and both Clippy checks passed, but the backend tests exhausted the runner's thread limit: 31 failures included reader/thread spawn errors with `EAGAIN`.

The new Speed matrix created a database pool for each of its 54 cases. Each r2d2 pool starts three scheduled workers; its default 30-second maintenance job remains pending after drop because scheduled-thread-pool defaults to `CompletePendingScheduled`. A temporary diagnostic on the isolated original test measured 2 threads before, 173 after, 173 after one second and 29 after 31 seconds. This is retained background work, rather than a permanent forwarder leak: `kill` stops and joins each fake-session output forwarder. The fixture now creates one pool per runtime (six pools), explicitly resets role and slot Speed for every combination, and still checks all 54 persisted/argv results against the unchanged golden.

The diagnostic also exposed rollout capture reading the real home in test builds even when a conversation fixture home was installed. Codex and TRAE now select the existing fixture-home helper only in test builds; production still selects `runner_core::app_paths::home_dir`. `rollout_capture_uses_fixture_home` verifies both paths and scope restoration. The golden normalizer labels capture roots as `<HOME>` when the fixture home shares the temporary app-data root, retaining every frozen expectation byte. The final isolated Speed diagnostic measured 2 threads before, 29 immediately after and 20 after one second: 18 database workers from six pools, with the short-lived Antigravity capture workers gone. Diagnostic instrumentation was removed before final validation; its logs remain under `/private/tmp/777-validation/speed-thread-profile-{original,reused,fixed}.log`.

These fixes affect test compilation and fixtures only. App UI and production behavior are unchanged, so the recorded native QA gaps and manual checks still apply.

Final local follow-up gates: workspace tests 1,904 passed, 0 failed, 3 ignored; workspace Clippy, updater Clippy, format, diff and the 19 frozen expectation checks each exit 0.
