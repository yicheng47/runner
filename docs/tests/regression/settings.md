# Settings

Use native UI plus disk/CLI readback for writes. All install, skill, MCP, update and agent-configuration actions require test-owned isolated fixtures or explicit authorization for that exact existing installation. Ordinary live account reuse does not authorize changing global settings. Use the [procedure](../full-smoke-test.md), retain original fixture state and restore test changes. Package/update rows require separately supplied authorized artifacts and environments; a development preview cannot prove a production installation.
