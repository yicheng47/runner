# Linux

Run on each required architecture and desktop backend, recording distro, glibc, ARM64/x86_64, X11/Wayland, graphics driver and package identity. Ubuntu ARM64 VM observations do not establish physical-hardware, x86_64, other-distro or WSLg acceptance. Use only owned development data; package, service, authorization and update cases require an expressly approved disposable installation. RPM is not shipped: use tar/deb packages. Current authority is [Linux architecture](../../arch/linux.md), [packaging](../../../script/bundle-linux), [installer](../../../crates/runner-app/src/updater/linux/install.rs) and the [platform contract](../../features/archive/823-linux-support.md).
