# Runtimes

Run each applicable row separately for Codex, Claude Code, Antigravity CLI, Copilot and pi, on each required platform. TRAE is an additional runtime when access is available, with baseline status and only its supported controls; it is opt-in, so enable it in Settings → Agents for the run. Cursor, Grok Build and OpenCode are enabled by default and also additional: run their instances when the change touches them or the run's scope names them. An unavailable required runtime is Blocked. These are case templates, not five duplicated lists. Use the [procedure](../full-smoke-test.md) for account isolation, native input, canonical scratch directories, startup goals and cleanup.

Record native terminal evidence and `session show <id> --json` at first completion, active tool, interruption, recovery, stop, resume, conversation change and its resume. Inspect lifecycle separately from `agent_status.observation.activity`, `source`, `outcome`, detail and interactions. A running process can be Idle. Hook-supported runtimes should report hook authority after real work: all five on macOS, all except Antigravity on Windows. Grok Build reports through hooks on macOS only; its hooks are off on Windows, where status is the terminal baseline. OpenCode reports through its TUI plugin over the same hook transport and falls back to the terminal baseline when that bridge is unavailable. Unsupported or explicitly disabled hooks use an identified baseline and cannot prove successful completion from silence.

Current authority: [runtime adapters](../../../crates/runner-daemon/src/runtimes/mod.rs), [launch/resume](../../../crates/runner-daemon/src/session/manager/spawn.rs), [session model](../../../crates/runner-daemon/src/session/state/mod.rs), [Codex hook configuration](../../../crates/runner-daemon/src/runtimes/codex/mod.rs) and [pi status/drafts](../../../crates/runner-daemon/src/runtimes/pi/pi_status.rs). Production status and rekey reports use IPC. Old feed/helper-file recipes in origins are historical, not live prerequisites.

## Lifecycle core

Use unique `SMOKE-<run>-<runtime>-ORIGINAL` and `...-NEW` markers. Focus the visible input again after a process resume. A CLI start/resume returning success cannot substitute for rendering, input or blind recall.

If a wait is backgrounded, record which foreground operation was interrupted and do not claim the background work stopped. Keep the task bounded, recover or stop the owned session, and verify no test descendants survive cleanup.
