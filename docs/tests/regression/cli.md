# CLI

Use the absolute candidate development sidecar and [procedure](../full-smoke-test.md), with child mission identity unset for outside-mission calls. Inside an owned slot, keep that slot's real identity. Capture argv, real child exit code, stdout/stderr and parsed JSON. Use supported commands/help, never direct SQLite/private PTY writes or `--as` to impersonate another slot. Live daemon/feed checks are separate from the exhaustive schema/output tests in the crates.

Current authority: [CLI](../../../crates/runner-cli/src/main.rs), [client protocol](../../../crates/runner-core/src/protocol/mod.rs), [daemon server](../../../crates/runner-daemon/src/daemon/server.rs) and [version-matched guide](../../../crates/runner-cli/src/help.rs). The CLI uses `runnerd.sock`/daemon named pipe. Legacy MCP endpoint is a rejection sentinel, not the command transport. Cockpit close with Keep leaves the CLI usable.
